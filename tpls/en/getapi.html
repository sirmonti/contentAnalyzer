Content Analyzer Extension

Get a Free API Key

To use the Content Analyzer effectively, you will need to configure an AI provider. While some providers charge for their usage, there are excellent free options available.

Below you will find instructions on how to obtain free API keys or set up services across popular platforms: Google Gemini, OpenRouter, Groq, Mistral AI, and Ollama.

1

Google Gemini

Google offers access to its advanced Gemini models through Google AI Studio. They provide a generous free tier for developers. Note that the models that can be used for free are those containing the word "lite" in their name, such as gemini-3.1-flash-lite or gemini-flash-lite-latest.

  • Visit the Google AI Studio website.
  • Sign in with your Google account.
  • On the left-hand navigation menu, click on "Get API key".
  • Click on the "Create API key" button. You can choose to create it in an existing Google Cloud project or let AI Studio create a new one for you.
  • Copy the generated key and paste it into the Content Analyzer's Options page under the Gemini provider settings.
2

OpenRouter.ai

OpenRouter is a unified interface for multiple AI models. It aggregates models from various providers, and several high-quality models are available completely for free.

  • Go to the OpenRouter.ai homepage.
  • Sign up or log in using an existing account (Google, GitHub, etc.).
  • Once logged in, navigate to the "Keys" section from the main menu or your account settings.
  • Click on "Create Key". Give it a name like "Content Analyzer".
  • Copy your new API key. In Content Analyzer, select the OpenRouter provider option, paste your API key, and select or enter your chosen model's ID (e.g., google/gemini-2.5-flash:free).
3

Groq

Groq provides extremely fast inference for open-source AI models. They currently offer a free tier with high performance for developers.

  • Visit the Groq Console.
  • Sign up or log in using an existing account.
  • Navigate to the "API Keys" section in the sidebar.
  • Click on "Create API Key" and give it a descriptive name.
  • Copy the generated API key. In Content Analyzer, select the Groq provider option, paste your API key, and select your chosen model from the list (e.g., llama-3.3-70b-versatile).
4

Mistral AI

Mistral AI provides access to state-of-the-art open and commercial models through La Plateforme, offering free tiers for developers to experiment.

  • Visit the Mistral AI Console.
  • Sign up or log in to your account.
  • Navigate to the "API Keys" section from the workspace navigation.
  • Click on "Create new key" and copy your generated API key.
  • In Content Analyzer, select the Mistral AI provider option, paste your API key, and select your chosen model from the list (e.g., mistral-small-latest, mistral-large-latest, or codestral-latest).
5

Ollama (ollama.com)

Ollama provides an online API service allowing you to connect directly to hosted models via their web platform.

  • Visit the Ollama.com website.
  • Log in to your account or sign up if you do not have one yet.
  • Click on your user menu located at the top right corner of the page.
  • Select the "Settings" option.
  • Select the "Keys" section.
  • Click on "Add API key" and generate your API key.
  • In Content Analyzer, choose the Ollama API type and set the Base URL to https://ollama.com/, and enter your chosen model ID (e.g., gemma4:31b).
