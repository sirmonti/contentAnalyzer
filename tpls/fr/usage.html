Extension d’analyse de contenu

Guide d’utilisation et de configuration

L’analyseur de contenu est une extension de navigateur conçue pour l’extraction et l’évaluation automatisées des métadonnées sémantiques dans des environnements Web complexes. Cette extension fonctionne sur Firefox, Chrome et les navigateurs dérivés de Chromium. Son objectif principal est de traiter le contenu Web en le faisant passer par divers services d’intelligence artificielle (IA).

Contrairement aux outils de résumé de pages Web classiques, cette extension vous permet de créer plusieurs services d’IA personnalisés, chacun avec un ensemble d’instructions très précis qui indiquent exactement ce que l’IA doit faire avec les informations collectées. Vous pouvez l’utiliser pour extraire du code, traduire des termes spécifiques, analyser le sentiment, générer des rapports ciblés, et bien plus encore.

Fonctionnalités principales

  • Capture de contenu personnalisée : Vous pouvez facilement sélectionner une partie spécifique d’une page Web à l’aide d’un « outil de survol » interactif, ou choisir de capturer tout le contenu de la page.
  • Instructions et instructions système d’IA personnalisées : Créez différents services adaptés à vos besoins exacts avec des instructions utilisateur personnalisées et des instructions système facultatives (par exemple, « Résumer l’article », « Extraire les données JSON », « Traduire en espagnol », personnalisation de la personnalité de l’assistant, etc.).
  • Services spécifiques à un domaine : Vous pouvez associer vos services personnalisés à des domaines Web spécifiques. Cela permet de maintenir votre extension propre en n’affichant que les outils d’IA pertinents.
  • Compatibilité étendue avec les LLM : Prend entièrement en charge les connexions (y compris la diffusion de texte) avec des serveurs locaux via Ollama, ainsi que les fournisseurs d’API cloud tels qu’OpenAI, Anthropic et Google Gemini.
2

Fournisseurs d’IA pris en charge

Cette extension est conçue pour être très flexible, ce qui vous permet de vous connecter à une variété de modèles d’intelligence artificielle et de services locaux de premier plan. Actuellement, elle prend en charge :

  • Claude (Anthropic) : Accédez à la puissante famille de modèles Claude via leur API officielle.
  • Gemini (Google) : Connectez-vous directement aux modèles Gemini avancés de Google.
  • ChatGPT (OpenAI et compatibles) : Entièrement compatible avec l’API d’OpenAI, ainsi qu’avec tout autre service tiers qui propose une API compatible OpenAI.
  • Ollama : Exécutez des modèles localement et en privé sur votre propre machine sans envoyer de données vers le cloud.
3

Balises dynamiques pour les instructions

Pour rendre vos instructions d’IA plus contextuelles et plus performantes, vous pouvez utiliser les balises dynamiques suivantes dans les instructions utilisateur et les instructions système. L’extension les substituera automatiquement avant d’envoyer l’instruction au modèle d’IA :

Balise Description
{DATE} Remplacée par la date actuelle dans votre format local.
{HOUR} Remplacée par l’heure actuelle dans votre format local.
{URL} L’URL complète de la page Web en cours de traitement.
{DOMAIN} Le domaine racine de la page Web en cours de traitement.
{LANG} La langue de la page Web.
{SYSLANG} La configuration actuelle de la langue du système/du navigateur.
{TITLE} Le titre HTML de la page Web en cours de traitement.

Exemples de configurations

Voici quelques exemples illustrant comment vous pouvez structurer vos services :

Exemple 1 : Assistant de traduction multilingue

Nom du service : Traduire dans la langue locale
Domaines associés : (Vide – Disponible partout)

Agissez comme un traducteur professionnel. Je navigue sur un site dans la langue {LANG} à l’adresse {URL}, mais mon navigateur est réglé sur {SYSLANG}. Veuillez traduire avec précision le contenu suivant dans {SYSLANG}, en conservant la mise en forme originale du texte et du balisage.

Exemple 2 : Analyseur de code (spécifique à un domaine)

Nom du service : Analyse de code Python
Domaines associés : github.com, gitlab.com, stackoverflow.com

Vous êtes un développeur expert. Les extraits de code fournis ci-dessous ont été trouvés sur {DOMAIN}. Analysez le code en recherchant strictement les bogues potentiels, les vulnérabilités de sécurité et les problèmes de qualité du code. N’expliquez pas ce que fait le code, mais listez simplement les problèmes et fournissez une version corrigée.

Exemple 3 : Extracteur de résumé quotidien

Nom du service : Extraire les entités clés
Domaines associés : news.ycombinator.com, techcrunch.com, bbc.com

Aujourd’hui, nous sommes le {DATE} à {HOUR}. Analysez l’article de presse suivant et extrayez une liste JSON propre contenant les principaux « Personnes », « Organisations » et « Lieux » mentionnés dans le texte.

Exemple 4 : Personnalisation de l’assistant (instruction système)

Nom du service : Assistant Mario
Instruction système :

Vous êtes Mario, un assistant intelligent et vif. Votre travail consiste à accomplir les tâches qui vous sont assignées de la manière la plus efficace possible. Pour les tâches qui ont des références temporelles, vous devez garder à l’esprit qu’aujourd’hui, nous sommes le {DATE}.

Instruction utilisateur :

Analysez le texte suivant extrait de {URL} et fournissez un résumé des points principaux.

Installation sur le navigateur

Le processus d’installation se fait via le dépôt officiel ou en chargeant le package décompressé en mode développeur.

  • Google Chrome : Télécharger depuis le Chrome Web Store.
  • Mozilla Firefox : Télécharger depuis les modules complémentaires de Firefox.
  • Alternativement, vous pouvez charger l’extension décompressée en mode développeur via chrome://extensions/ ou about:debugging.
info
Remarque : Assurez-vous d’avoir correctement configuré les paramètres globaux (clés d’API ou instances Ollama locales) dans la page des options de l’extension avant d’exécuter des captures.
