Extension d'analyse de contenu

Guide d'utilisation et de configuration

L'Analyseur de contenu est une extension de navigateur conçue pour l'extraction et l'évaluation automatisées de métadonnées sémantiques dans des environnements web complexes. Cette extension fonctionne sur Firefox, Chrome et les navigateurs dérivés de Chromium. Son objectif principal est de traiter le contenu web en le transmettant à divers services d'intelligence artificielle (IA).

Contrairement aux outils classiques de résumé de pages web, cette extension vous permet de créer plusieurs services IA personnalisés, chacun avec une invite très spécifique qui indique exactement ce que l'IA doit faire avec les informations collectées. Vous pouvez l'utiliser pour extraire du code, traduire des termes spécifiques, analyser le sentiment, générer des rapports ciblés, et bien plus encore.

Fonctionnalités principales

  • Capture de contenu personnalisée : Vous pouvez facilement sélectionner une partie spécifique d'une page web à l'aide d'un « outil de survol » interactif, ou choisir de capturer tout le contenu de la page.
  • Multiples invites et invites système IA personnalisées : Créez différents services adaptés à vos besoins exacts avec des invites utilisateur personnalisées et des invites système optionnelles (par exemple, « Résumer l'article », « Extraire les données JSON », « Traduire en espagnol », des personnalités d'assistant personnalisées, etc.).
  • Services spécifiques à un domaine : Vous pouvez associer vos services personnalisés à des domaines web spécifiques. Cela permet de maintenir une extension propre en n'affichant que les outils IA pertinents.
  • Compatibilité étendue avec les LLM : Prend entièrement en charge les connexions (y compris le streaming de texte) avec des serveurs locaux via Ollama, ainsi que les fournisseurs d'API cloud tels qu'OpenAI, Anthropic et Google Gemini.
2

Fournisseurs d'IA pris en charge

Cette extension est conçue pour être très flexible, ce qui vous permet de vous connecter à une variété de modèles d'intelligence artificielle et de services locaux leaders du marché. Actuellement, elle prend en charge :

  • Claude (Anthropic) : Accédez à la puissante famille de modèles Claude via leur API officielle.
  • Gemini (Google) : Connectez-vous directement aux modèles avancés Gemini de Google.
  • ChatGPT (OpenAI et compatibles) : Entièrement compatible avec l'API d'OpenAI, ainsi qu'avec tout autre service tiers qui propose une extrémité compatible OpenAI.
  • Ollama : Exécutez des modèles localement et en privé sur votre propre machine sans envoyer de données vers le cloud.
3

Balises dynamiques pour les invites

Afin de rendre vos invites IA plus contextuelles et plus puissantes, vous pouvez utiliser les balises dynamiques suivantes dans les invites utilisateur et les invites système. L'extension les remplacera automatiquement avant d'envoyer l'invite au modèle IA :

Balise Description
{DATE} Remplacée par la date actuelle dans votre format local.
{HOUR} Remplacée par l'heure actuelle dans votre format local.
{URL} L'URL complète de la page web en cours de traitement.
{DOMAIN} Le domaine racine de la page web en cours de traitement.
{LANG} La langue de la page web.
{SYSLANG} La configuration actuelle de la langue du système/navigateur.

Exemples de configurations

Voici quelques exemples illustrant la manière dont vous pouvez structurer vos services :

Exemple 1 : Assistant de traduction multilingue

Nom du service : Traduire dans la langue locale
Domaines associés : (Vide - Disponible partout)

Agissez en tant que traducteur professionnel. Je navigue sur un site dans la langue {LANG} à l'adresse {URL}, mais mon navigateur est configuré en {SYSLANG}. Veuillez traduire avec précision le contenu suivant en {SYSLANG}, en conservant la mise en forme et le formatage du texte d'origine.

Exemple 2 : Révision de code (spécifique à un domaine)

Nom du service : Vérification de code Python
Domaines associés :github.com, gitlab.com, stackoverflow.com

Vous êtes un développeur expert. Les extraits de code fournis ci-dessous ont été trouvés sur {DOMAIN}. Analysez le code en recherchant strictement les bogues potentiels, les vulnérabilités de sécurité et les problèmes de qualité du code. N'expliquez pas ce que fait le code, mais énumérez simplement les problèmes et fournissez une version corrigée.

Exemple 3 : Extraction d'informations pour un résumé quotidien

Nom du service : Extraire les entités clés
Domaines associés :news.ycombinator.com, techcrunch.com, bbc.com

Aujourd'hui, nous sommes le {DATE} à {HOUR}. Analysez l'article de presse suivant et extrayez une liste JSON propre contenant les principaux « personnes », « organisations » et « lieux » mentionnés dans le texte.

Exemple 4 : Personnalité d'assistant personnalisée (invite système)

Nom du service :Assistant Mario
Invite système :

Vous êtes Mario, un assistant intelligent et compétent. Votre tâche est d'accomplir les tâches qui vous sont assignées de la manière la plus efficace possible. Pour les tâches qui contiennent des références temporelles, n'oubliez pas qu'aujourd'hui nous sommes le {DATE}.

Invite utilisateur :

Analysez le texte suivant capturé à partir de {URL} et fournissez un résumé des points principaux.
5

Installation sur le navigateur

L'installation se fait via le dépôt officiel ou en chargeant le package décompressé en mode développeur.

  • Google Chrome : Télécharger depuis le Chrome Web Store.
  • Mozilla Firefox : Télécharger depuis les modules complémentaires de Firefox.
  • Alternativement, vous pouvez charger l'extension décompressée en mode développeur via chrome://extensions/ ou about:debugging.
info
Remarque : Assurez-vous d'avoir correctement configuré les paramètres globaux (clés API ou instances Ollama locales) dans la page Options de l'extension avant d'exécuter des captures.
