Extension d'analyse de contenu

Obtenez une clé API gratuite

Pour utiliser efficacement l'Analyseur de contenu, vous devrez configurer un fournisseur d'IA. Bien que certains fournisseurs facturent leur utilisation, il existe d'excellentes options gratuites.

Vous trouverez ci-dessous des instructions sur la manière d'obtenir des clés API gratuites ou de configurer des services sur les plateformes populaires : Google Gemini, OpenRouter, Groq, Mistral AI et Ollama.

1

Google Gemini

Google offre un accès à ses modèles avancés Gemini via Google AI Studio. Ils proposent une version gratuite généreuse pour les développeurs. Notez que les modèles qui peuvent être utilisés gratuitement sont ceux qui contiennent le mot "lite" dans leur nom, tels que gemini-3.1-flash-lite ou gemini-flash-lite-latest.

  • Visitez le site web de Google AI Studio.
  • Connectez-vous avec votre compte Google.
  • Dans le menu de navigation à gauche, cliquez sur "Obtenir une clé API".
  • Cliquez sur le bouton "Créer une clé API". Vous pouvez choisir de la créer dans un projet Google Cloud existant ou laisser AI Studio en créer un pour vous.
  • Copiez la clé générée et collez-la dans la page Options de l'analyseur de contenu, sous les paramètres du fournisseur Gemini.
2

OpenRouter.ai

OpenRouter est une interface unifiée pour plusieurs modèles d'IA. Il regroupe les modèles de divers fournisseurs, et plusieurs modèles de haute qualité sont disponibles gratuitement.

  • Accédez à la page d'accueil OpenRouter.ai.
  • Inscrivez-vous ou connectez-vous en utilisant un compte existant (Google, GitHub, etc.).
  • Une fois connecté, accédez à la section "Clés" dans le menu principal ou les paramètres de votre compte.
  • Cliquez sur "Créer une clé". Donnez-lui un nom tel que "Analyseur de contenu".
  • Copiez votre nouvelle clé API. Dans l'analyseur de contenu, vous pouvez utiliser cette clé en sélectionnant l'option de compatibilité OpenAI, en définissant l'URL de base sur https://openrouter.ai/api/v1 et en entrant l'ID du modèle que vous avez choisi (par exemple, google/gemini-2.5-flash:free).
3

Groq

Groq offre une inférence extrêmement rapide pour les modèles d'IA open source. Ils proposent actuellement un plan gratuit avec des performances élevées pour les développeurs.

  • Visitez la Console Groq.
  • Inscrivez-vous ou connectez-vous en utilisant un compte existant.
  • Accédez à la section "Clés API" dans la barre latérale.
  • Cliquez sur "Créer une clé API" et donnez-lui un nom descriptif.
  • Copiez la clé API générée. Dans l'analyseur de contenu, utilisez l'option de compatibilité OpenAI, définissez l'URL de base sur https://api.groq.com/openai/v1, et entrez l'ID du modèle que vous avez choisi (par exemple, llama3-8b-8192).
4

Mistral AI

Mistral AI offre un accès à des modèles open source et commerciaux de pointe via La Plateforme, proposant des plans gratuits aux développeurs pour qu'ils puissent expérimenter.

  • Visitez la Console Mistral AI.
  • Inscrivez-vous ou connectez-vous à votre compte.
  • Accédez à la section "Clés API" depuis la navigation de l'espace de travail.
  • Cliquez sur "Créer une nouvelle clé" et copiez votre clé API générée.
  • Dans l'analyseur de contenu, sélectionnez l'option de compatibilité OpenAI, définissez l'URL de base sur https://api.mistral.ai/v1, et entrez l'ID du modèle que vous avez choisi (par exemple, mistral-small-latest).
5

Ollama (ollama.com)

Ollama fournit un service API en ligne qui vous permet de vous connecter directement aux modèles hébergés via leur plateforme web.

  • Visitez le site web Ollama.com.
  • Connectez-vous à votre compte ou inscrivez-vous si vous n'en avez pas encore un.
  • Cliquez sur votre menu utilisateur situé en haut à droite de la page.
  • Sélectionnez l'option "Paramètres".
  • Sélectionnez la section "Clés".
  • Cliquez sur "Ajouter une clé API" et générez votre clé API.
  • Dans l'analyseur de contenu, choisissez le type d'API Ollama, définissez l'URL de base sur https://ollama.com/, et entrez l'ID du modèle que vous avez choisi (par exemple, gemma4:31b).
