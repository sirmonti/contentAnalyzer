Content Analyzer-Erweiterung

Anleitung zur Nutzung und Konfiguration

Der Content Analyzer ist eine Browser-Erweiterung, die für die automatisierte Extraktion und Auswertung semantischer Metadaten in komplexen Web-Umgebungen entwickelt wurde. Diese Erweiterung funktioniert in Firefox, Chrome und Chromium-basierten Browsern; ihr Hauptzweck besteht darin, Webinhalte zu verarbeiten, indem sie durch verschiedene Dienste der Künstlichen Intelligenz (KI) geleitet werden.

Im Gegensatz zu typischen Webseiten-Zusammenfassern ermöglicht diese Erweiterung die Erstellung mehrerer benutzerdefinierter KI-Dienste, von denen jeder einen hochspezifischen Prompt besitzt, der genau festlegt, was die KI mit den gesammelten Informationen tun soll. Sie können sie verwenden, um Code zu extrahieren, spezifische Begriffe zu übersetzen, Stimmungen zu analysieren, gezielte Berichte zu erstellen und vieles mehr.

Hauptmerkmale

  • Benutzerdefinierte Inhaltserfassung: Sie können mit einem interaktiven „Hover-Tool“ einfach einen bestimmten Teil einer Webseite auswählen oder die Option wählen, den gesamten Seiteninhalt zu erfassen.
  • Mehrere benutzerdefinierte KI-Prompts & System-Prompts: Erstellen Sie verschiedene Dienste, die genau auf Ihre Bedürfnisse zugeschnitten sind, mit benutzerdefinierten Benutzer-Prompts und optionalen System-Prompts (z. B. „Artikel zusammenfassen“, „JSON-Daten extrahieren“, „Nach Spanisch übersetzen“, benutzerdefinierte Assistenten-Personas usw.).
  • Domänenspezifische Dienste: Sie können Ihre benutzerdefinierten Dienste mit bestimmten Web-Domänen verknüpfen. Dies hilft dabei, die Übersicht in Ihrer Erweiterung zu behalten, da nur die relevanten KI-Tools angezeigt werden.
  • Umfassende LLM-Kompatibilität: Unterstützt vollständig Verbindungen (einschließlich Text-Streaming) mit lokalen Servern über Ollama sowie Cloud-API-Anbieter wie Anthropic (Claude), Google Gemini, Groq, OpenRouter, Mistral AI und OpenAI.
2

Unterstützte KI-Anbieter

Diese Erweiterung wurde so konzipiert, dass sie sehr flexibel ist und die Verbindung zu einer Vielzahl führender KI-Modelle und lokaler Dienste ermöglicht. Derzeit werden folgende unterstützt:

  • Claude (Anthropic): Zugriff auf die leistungsstarke Claude-Modellfamilie über deren offizielle API.
  • Gemini (Google): Direkte Verbindung zu Googles fortschrittlichen Gemini-Modellen.
  • Groq: Ultra-schnelle Inferenz mit dedizierten Llama-, Mixtral- und Gemma-Modellen.
  • OpenRouter: Einheitlicher Zugriff auf einen großen Katalog an KI-Modellen verschiedener Anbieter.
  • Mistral AI: Verbindung zu hochmodernen offenen und kommerziellen Mistral-Modellen über deren offizielle API.
  • ChatGPT (OpenAI & Kompatible): Vollständig kompatibel mit der OpenAI-API sowie mit allen anderen Drittanbieterdiensten, die einen OpenAI-kompatiblen Endpunkt anbieten.
  • Ollama (oder Kompatible): Führen Sie Modelle lokal und privat auf Ihrem eigenen Gerät aus, ohne Daten in die Cloud zu senden.
3

Dynamische Prompt-Tags

Um Ihre KI-Prompts kontextbezogener und leistungsfähiger zu gestalten, können Sie die folgenden dynamischen Tags sowohl in Benutzer-Prompts als auch in System-Prompts verwenden. Die Erweiterung ersetzt diese automatisch, bevor der Prompt an das KI-Modell gesendet wird:

Tag Beschreibung
{DATE} Wird durch das aktuelle Datum in Ihrem lokalen Format ersetzt.
{HOUR} Wird durch die aktuelle Uhrzeit in Ihrem lokalen Format ersetzt.
{URL} Die vollständige URL der gerade verarbeiteten Webseite.
{DOMAIN} Die Hauptdomain der verarbeiteten Webseite.
{LANG} Die Sprache der Webseite.
{SYSLANG} Die aktuelle System-/Browser-Sprachkonfiguration.
{TITLE} Der HTML-Titel der gerade verarbeiteten Webseite.
4

Beispielkonfigurationen

Unten finden Sie einige Beispiele, die zeigen, wie Sie Ihre Dienste strukturieren können:

Beispiel 1: Mehrsprachiger Übersetzungsassistent

Service-Name: In die Landessprache übersetzen
Verknüpfte Domains: (Leer - Überall verfügbar)

Agieren Sie als professioneller Übersetzer. Ich besuche eine Website in der Sprache {LANG} unter {URL}, aber mein Browser ist auf {SYSLANG} eingestellt. Bitte übersetzen Sie den folgenden Inhalt präzise in {SYSLANG} und behalten Sie dabei die ursprüngliche Markdown- und Textformatierung bei.

Beispiel 2: Code-Reviewer (domänenspezifisch)

Service-Name: Python Code Review
Verknüpfte Domains: github.com, gitlab.com, stackoverflow.com

Sie sind ein erfahrener Entwickler. Die unten bereitgestellten Code-Snippets wurden auf {DOMAIN} gefunden. Analysieren Sie den Code streng auf potenzielle Fehler, Sicherheitslücken und Code-Smells. Erklären Sie nicht, was der Code macht, listen Sie nur die Probleme auf und geben Sie eine korrigierte Version an.

Beispiel 3: Extraktor für tägliche Briefings

Service-Name: Wichtige Entitäten extrahieren
Verknüpfte Domains: news.ycombinator.com, techcrunch.com, bbc.com

Heute ist der {DATE} um {HOUR} Uhr. Scannen Sie den folgenden Nachrichtenartikel und erstellen Sie eine übersichtliche JSON-Liste, die die wichtigsten im Text erwähnten Personen, Organisationer und Orte enthält.

Beispiel 4: Benutzerdefinierte Assistenten-Persona (System-Prompt)

Service-Name: Mario-Assistent
System-Prompt:

Sie sind Mario, ein kluger und scharfsinniger Assistent. Ihre Aufgabe ist es, die Ihnen zugewiesenen Aufgaben so effizient wie möglich zu erfüllen. Bei Aufgaben mit Zeitbezug müssen Sie berücksichtigen, dass heute der {DATE} ist.

Benutzer-Prompt:

Analysieren Sie den folgenden aus {URL} erfassten Text und geben Sie eine Zusammenfassung der Hauptpunkte an.
5

Browser-Installation

Der Installationsprozess erfolgt über das offizielle Repository oder durch das Laden des ungepackten Pakets im Entwicklermodus.

  • Google Chrome: Download aus dem Chrome Web Store.
  • Mozilla Firefox: Download aus den Firefox Add-ons.
  • Alternativ können Sie die ungepackte Erweiterung im Entwicklermodus über chrome://extensions/ oder about:debugging laden.
info
Hinweis: Stellen Sie sicher, dass Sie die globalen Einstellungen (API-Schlüssel oder lokale Ollama-Instanzen) in der Options-Seite der Erweiterung korrekt konfiguriert haben, bevor Sie Erfassungen durchführen.
