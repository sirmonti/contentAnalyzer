Content Analyzer Extension

Anleitung zur Verwendung und Konfiguration

Der Content Analyzer ist eine Browsererweiterung, die für die automatisierte Extraktion und Auswertung semantischer Metadaten in komplexen Webumgebungen entwickelt wurde. Diese Erweiterung funktioniert auf Firefox, Chrome und Chromium-basierten Browsern. Ihr Hauptzweck ist die Verarbeitung von Webinhalten durch Weiterleitung an verschiedene Dienste der künstlichen Intelligenz (KI).

Im Gegensatz zu typischen Webseitenzusammenfassungsdiensten ermöglicht diese Erweiterung das Erstellen mehrerer benutzerdefinierter KI-Dienste, die jeweils über eine hochspezifische Eingabeaufforderung verfügen, die genau festlegt, was die KI mit den gesammelten Informationen tun soll. Sie können sie verwenden, um Code zu extrahieren, bestimmte Begriffe zu übersetzen, Stimmungen zu analysieren, gezielte Berichte zu erstellen und vieles mehr.

Hauptfunktionen

  • Benutzerdefinierte Inhaltsauswahl: Sie können ganz einfach einen bestimmten Teil einer Webseite mithilfe eines interaktiven „Hover“-Tools auswählen oder die gesamte Seiteninhalte erfassen.
  • Mehrere benutzerdefinierte KI-Eingabeaufforderungen und Systemeingabeaufforderungen: Erstellen Sie verschiedene Dienste, die auf Ihre genauen Bedürfnisse zugeschnitten sind, mit benutzerdefinierten Eingabeaufforderungen und optionalen Systemeingabeaufforderungen (z. B. „Artikel zusammenfassen“, „JSON-Daten extrahieren“, „ins Spanische übersetzen“, benutzerdefinierte Assistentenpersönlichkeiten usw.).
  • Domänenspezifischer Service: Sie können Ihre benutzerdefinierten Dienste bestimmten Webdomänen zuordnen. Dies trägt dazu bei, dass Ihre Erweiterung übersichtlich bleibt, indem nur relevante KI-Tools angezeigt werden.
  • Breite LLM-Kompatibilität: Bietet die vollständige Unterstützung von Verbindungen (einschließlich Textstreaming) mit lokalen Servern über Ollama sowie Cloud-API-Anbietern wie OpenAI, Anthropic und Google Gemini.
2

Unterstützte KI-Anbieter

Diese Erweiterung ist so konzipiert, dass sie hochgradig flexibel ist und die Verbindung zu einer Vielzahl branchenführender künstlicher Intelligenzmodelle und lokalen Dienste ermöglicht. Derzeit werden folgende Anbieter unterstützt:

  • Claude (Anthropic): Zugriff auf die leistungsstarke Claude-Familie von Modellen über deren offizielle API.
  • Gemini (Google): Direkte Verbindung zu Googles fortschrittlichen Gemini-Modellen.
  • ChatGPT (OpenAI & Kompatible): Vollständig kompatibel mit der OpenAI-API sowie allen anderen Drittanbietern, die ein OpenAI-kompatibles Endpunkt anbieten.
  • Ollama: Ausführen von Modellen lokal und privat auf Ihrem eigenen Computer, ohne Daten in die Cloud zu senden.
3

Dynamische Tags für Eingabeaufforderungen

Um Ihre KI-Eingabeaufforderungen kontextbezogener und leistungsfähiger zu gestalten, können Sie die folgenden dynamischen Tags sowohl in Benutzer- als auch in Systemeingabeaufforderungen verwenden. Die Erweiterung ersetzt diese automatisch, bevor sie an das KI-Modell gesendet werden:

Tag Beschreibung
{DATE} Wird durch das aktuelle Datum in Ihrem lokalen Format ersetzt.
{HOUR} Wird durch die aktuelle Uhrzeit in Ihrem lokalen Format ersetzt.
{URL} Die vollständige URL der derzeit verarbeiteten Webseite.
{DOMAIN} Die Stammdomäne der verarbeiteten Webseite.
{LANG} Die Sprache der Webseite.
{SYSLANG} Die aktuelle System-/Browsersprache.
4

Beispielkonfigurationen

Unten finden Sie einige Beispiele, die zeigen, wie Sie Ihre Dienste strukturieren können:

Beispiel 1: Mehrsprachiger Übersetzungsassistent

Dienstname: In die lokale Sprache übersetzen
Verknüpfte Domänen: (Leer - überall verfügbar)

Ich bin auf einer Webseite in der Sprache {LANG} unter {URL}, aber mein Browser ist auf {SYSLANG} eingestellt. Bitte übersetzen Sie den folgenden Inhalt genau in die Sprache {SYSLANG} und behalten Sie dabei das ursprüngliche Markdown und die Textformatierung bei.

Beispiel 2: Code-Reviewer (domänenspezifisch)

Dienstname: Python-Code-Review
Verknüpfte Domänen: github.com, gitlab.com, stackoverflow.com

Sie sind ein erfahrener Entwickler. Die folgenden Codeausschnitte wurden auf {DOMAIN} gefunden. Analysieren Sie den Code streng nach potenziellen Fehlern, Sicherheitslücken und problematischem Code. Erklären Sie nicht, was der Code tut, sondern listen Sie nur die Probleme auf und stellen Sie eine korrigierte Version bereit.

Beispiel 3: Extrahieren von täglichen Zusammenfassungen

Dienstname: Wichtige Entitäten extrahieren
Verknüpfte Domänen: news.ycombinator.com, techcrunch.com, bbc.com

Heute ist {DATE} um {HOUR}. Scannen Sie den folgenden Nachrichtenartikel und extrahieren Sie eine übersichtliche JSON-Liste, die die wichtigsten "Personen", "Organisationen" und "Orte" enthält, die im Text erwähnt werden.

Beispiel 4: Benutzerdefinierte Assistentenpersönlichkeit (Systemeingabeaufforderung)

Dienstname: Mario-Assistent
Systemeingabeaufforderung:

Du bist Mario, ein intelligenter und scharfsinniger Assistent. Deine Aufgabe ist es, die dir zugewiesenen Aufgaben so effizient wie möglich zu erledigen. Bei Aufgaben, die zeitliche Bezüge haben, musst du daran denken, dass heute {DATE} ist.

Benutzereingabeaufforderung:

Analysiere den folgenden Text, der von {URL} abgerufen wurde, und erstelle eine Zusammenfassung der wichtigsten Punkte.
5

Browserinstallation

Die Installation erfolgt über das offizielle Repository oder durch Laden des entpackten Pakets im Entwicklermodus.

  • Google Chrome: Herunterladen aus dem Chrome Web Store.
  • Mozilla Firefox: Herunterladen von Firefox Add-ons.
  • Alternativ können Sie die entpackte Erweiterung im Entwicklermodus über chrome://extensions/ oder about:debugging laden.
info
Hinweis: Stellen Sie sicher, dass Sie die globalen Einstellungen (API-Schlüssel oder lokale Ollama-Instanzen) in der Optionsseite der Erweiterung korrekt konfigurieren, bevor Sie Captures ausführen.
