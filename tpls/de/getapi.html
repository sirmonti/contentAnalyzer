Content Analyzer Erweiterung

Kostenlosen API-Schlüssel erhalten

Um den Content Analyzer effektiv zu nutzen, müssen Sie einen KI-Anbieter konfigurieren. Während einige Anbieter für ihre Nutzung Gebühren erheben, gibt es auch ausgezeichnete kostenlose Optionen.

Im Folgenden finden Sie Anleitungen zum Abrufen kostenloser API-Schlüssel oder zur Einrichtung von Diensten auf beliebten Plattformen: Google Gemini, OpenRouter, Groq, Mistral AI und Ollama.

1

Google Gemini

Google bietet über Google AI Studio Zugriff auf seine fortschrittlichen Gemini-Modelle. Sie stellen Entwicklern ein großzügiges kostenloses Kontingent zur Verfügung. Beachten Sie, dass die Modelle, die kostenlos verwendet werden können, diejenigen sind, die das Wort „lite“ in ihrem Namen enthalten, wie z. B. gemini-3.1-flash-lite oder gemini-flash-lite-latest.

  • Besuchen Sie die Google AI Studio-Website.
  • Melden Sie sich mit Ihrem Google-Konto an.
  • Klicken Sie im linken Navigationsmenü auf "API-Schlüssel abrufen".
  • Klicken Sie auf die Schaltfläche "API-Schlüssel erstellen". Sie können ihn in einem vorhandenen Google Cloud-Projekt erstellen oder AI Studio einen neuen für Sie erstellen lassen.
  • Kopieren Sie den generierten Schlüssel und fügen Sie ihn auf der Optionsseite des Content Analyzer unter den Einstellungen für den Gemini-Anbieter ein.
2

OpenRouter.ai

OpenRouter ist eine einheitliche Schnittstelle für mehrere KI-Modelle. Es aggregiert Modelle von verschiedenen Anbietern, und es stehen mehrere hochwertige Modelle vollständig kostenlos zur Verfügung.

  • Gehen Sie auf die OpenRouter.ai-Homepage.
  • Registrieren Sie sich oder melden Sie sich mit einem vorhandenen Konto (Google, GitHub usw.) an.
  • Navigieren Sie nach der Anmeldung im Hauptmenü oder in Ihren Kontoeinstellungen zum Abschnitt "Schlüssel".
  • Klicken Sie auf "Schlüssel erstellen". Geben Sie ihm einen Namen wie „Content Analyzer“.
  • Kopieren Sie Ihren neuen API-Schlüssel. Im Content Analyzer können Sie diesen Schlüssel verwenden, indem Sie die OpenAI-Kompatibilitätsoption auswählen, die Basis-URL auf https://openrouter.ai/api/v1 setzen und die ID Ihres ausgewählten Modells eingeben (z. B. google/gemini-2.5-flash:free).
3

Groq

Groq bietet extrem schnelle Inferenz für Open-Source-KI-Modelle. Sie bieten derzeit ein kostenloses Kontingent mit hoher Leistung für Entwickler.

  • Besuchen Sie die Groq Console.
  • Registrieren Sie sich oder melden Sie sich mit einem vorhandenen Konto an.
  • Navigieren Sie zum Abschnitt "API-Schlüssel" in der Seitenleiste.
  • Klicken Sie auf "API-Schlüssel erstellen" und geben Sie ihm einen beschreibenden Namen.
  • Kopieren Sie den generierten API-Schlüssel. Verwenden Sie im Content Analyzer die OpenAI-Kompatibilitätsoption, setzen Sie die Basis-URL auf https://api.groq.com/openai/v1 und geben Sie die ID Ihres ausgewählten Modells ein (z. B. llama3-8b-8192).
4

Mistral AI

Mistral AI bietet über La Plateforme Zugriff auf hochmoderne Open-Source- und kommerzielle Modelle und stellt Entwicklern kostenlose Kontingente zum Experimentieren zur Verfügung.

  • Besuchen Sie die Mistral AI Console.
  • Registrieren Sie sich oder melden Sie sich in Ihrem Konto an.
  • Navigieren Sie von der Workspace-Navigation zum Abschnitt "API-Schlüssel".
  • Klicken Sie auf "Neuen Schlüssel erstellen" und kopieren Sie Ihren generierten API-Schlüssel.
  • Wählen Sie im Content Analyzer die OpenAI-Kompatibilitätsoption, setzen Sie die Basis-URL auf https://api.mistral.ai/v1 und geben Sie Ihre ausgewählte Modell-ID ein (z. B. mistral-small-latest).
5

Ollama (ollama.com)

Ollama bietet einen Online-API-Dienst, mit dem Sie sich direkt über ihre Webplattform mit gehosteten Modellen verbinden können.

  • Besuchen Sie die Ollama.com-Website.
  • Melden Sie sich in Ihrem Konto an oder registrieren Sie sich, falls Sie noch keines haben.
  • Klicken Sie auf Ihr Benutzermenü oben rechts auf der Seite.
  • Wählen Sie die Option "Einstellungen".
  • Wählen Sie den Abschnitt "Schlüssel".
  • Klicken Sie auf "API-Schlüssel hinzufügen" und generieren Sie Ihren API-Schlüssel.
  • Wählen Sie im Content Analyzer den API-Typ Ollama, setzen Sie die Basis-URL auf https://ollama.com/ und geben Sie Ihre ausgewählte Modell-ID ein (z. B. gemma4:31b).
