Extensão Content Analyzer

Guia de Uso e Configuração

O Content Analyzer é uma extensão de navegador projetada para a extração e avaliação automatizada de metadados semânticos em ambientes web complexos. Esta extensão funciona no Firefox, Chrome e navegadores derivados do Chromium; seu objetivo principal é processar conteúdo da web passando-o por diversos serviços de Inteligência Artificial (IA).

Ao contrário dos resumidores de páginas web típicos, esta extensão permite que você crie múltiplos serviços de IA personalizados, cada um com um prompt altamente específico que dita exatamente o que a IA deve fazer com as informações coletadas. Você pode usá-la para extrair código, traduzir termos específicos, analisar sentimentos, gerar relatórios direcionados e muito mais.

Principais Recursos

  • Captura de Conteúdo Personalizado: Você pode selecionar facilmente uma parte específica de uma página web usando uma "ferramenta de sobreposição" (hover tool) interativa, ou optar por capturar o conteúdo da página inteira.
  • Múltiplos Prompts de IA Personalizados & Prompts de Sistema: Crie diferentes serviços adaptados às suas necessidades exatas com prompts de usuário personalizados e Prompts de Sistema opcionais (ex: "Resumir artigo", "Extrair dados JSON", "Traduzir para espanhol", personas de assistentes personalizados, etc.).
  • Serviços Específicos por Domínio: Você pode vincular seus serviços personalizados a domínios web específicos. Isso ajuda a manter sua extensão limpa, exibindo apenas as ferramentas de IA relevantes.
  • Ampla Compatibilidade com LLM: Suporta totalmente conexões (incluindo streaming de texto) com servidores locais via Ollama, bem como provedores de API em nuvem como Anthropic (Claude), Google Gemini, Groq, OpenRouter, Mistral AI e OpenAI.
2

Provedores de IA Suportados

Esta extensão foi construída para ser altamente flexível, permitindo que você se conecte a uma variedade de modelos de Inteligência Artificial líderes do setor e serviços locais. Atualmente, ela suporta:

  • Claude (Anthropic): Acesse a poderosa família de modelos Claude por meio de sua API oficial.
  • Gemini (Google): Conecte-se diretamente aos modelos avançados Gemini do Google.
  • Groq: Inferência ultrarrápida com modelos dedicados Llama, Mixtral e Gemma.
  • OpenRouter: Acesso unificado a um vasto catálogo de modelos de IA de múltiplos provedores.
  • Mistral AI: Conecte-se a modelos Mistral abertos e comerciais de última geração via sua API oficial.
  • ChatGPT (OpenAI & Compatíveis): Totalmente compatível com a API da OpenAI, bem como com qualquer outro serviço de terceiros que ofereça um endpoint compatível com OpenAI.
  • Ollama (ou Compatíveis): Execute modelos localmente e de forma privada em sua própria máquina sem enviar dados para a nuvem.
3

Tags Dinâmicas de Prompt

Para tornar seus prompts de IA mais contextuais e poderosos, você pode utilizar as seguintes tags dinâmicas tanto em prompts de usuário quanto em Prompts de Sistema. A extensão os substituirá automaticamente antes de enviar o prompt para o modelo de IA:

Tag Descrição
{DATE} Substituído pela data atual no seu formato local.
{HOUR} Substituído pelo horário atual no seu formato local.
{URL} A URL completa da página da web que está sendo processada no momento.
{DOMAIN} O domínio raiz da página da web que está sendo processada.
{LANG} O idioma da página da web.
{SYSLANG} A configuração de idioma atual do sistema/navegador.
{TITLE} O título HTML da página da web que está sendo processada no momento.

Configurações de Exemplo

Abaixo estão alguns exemplos mostrando como você pode estruturar seus serviços:

Exemplo 1: Assistente de Tradução Multilíngue

Nome do Serviço: Traduzir para o idioma local
Domínios vinculados: (Vazio - Disponível em todos os lugares)

Atue como um tradutor profissional. Estou navegando em um site no idioma {LANG} em {URL}, mas meu navegador está configurado para {SYSLANG}. Por favor, traduza o seguinte conteúdo para {SYSLANG} com precisão, mantendo a formatação original de markdown e texto intacta.

Exemplo 2: Revisor de Código (Específico por Domínio)

Nome do Serviço: Revisão de Código Python
Domínios vinculados: github.com, gitlab.com, stackoverflow.com

Você é um desenvolvedor especialista. Os trechos de código fornecidos abaixo foram encontrados em {DOMAIN}. Analise o código estritamente em busca de bugs potenciais, vulnerabilidades de segurança e problemas de design. Não explique o que o código faz, apenas liste os problemas e forneça uma versão corrigida.

Exemplo 3: Extrator de Resumo Diário

Nome do Serviço: Extrair Entidades Principais
Domínios vinculados: news.ycombinator.com, techcrunch.com, bbc.com

Hoje é {DATE} às {HOUR}. Examine o seguinte artigo de notícias e extraia uma lista JSON organizada contendo as principais "Pessoas", "Organizações" e "Locais" mencionados no texto.

Exemplo 4: Persona de Assistente Personalizada (Prompt de Sistema)

Nome do Serviço: Assistente Mario
Prompt de Sistema:

Você é o Mario, um assistente inteligente e perspicaz; seu trabalho é realizar as tarefas atribuídas a você da forma mais eficiente possível. Em tarefas que possuam referências temporais, você deve ter em mente que hoje é {DATE}

Prompt de Usuário:

Analise o seguinte texto capturado de {URL} e forneça um resumo dos principais pontos.

Instalação no Navegador

O processo de instalação é feito por meio do repositório oficial ou carregando o pacote descompactado no modo de desenvolvedor.

  • Google Chrome: Baixar na Chrome Web Store.
  • Mozilla Firefox: Baixar no Firefox Add-ons.
  • Alternativamente, você pode carregar a extensão descompactada no modo de desenvolvedor via chrome://extensions/ ou about:debugging.
info
Nota: Certifique-se de ter configurado corretamente as configurações globais (Chaves de API ou instâncias locais do Ollama) na página de Opções da extensão antes de executar qualquer captura.
