Extensão Analisador de Conteúdo

Obtenha uma Chave de API Gratuita

Para usar o Analisador de Conteúdo de forma eficaz, você precisará configurar um provedor de IA. Embora alguns provedores cobrem pelo uso, existem excelentes opções gratuitas disponíveis.

Abaixo, você encontrará instruções sobre como obter chaves de API gratuitas ou configurar serviços em plataformas populares: Google Gemini, OpenRouter, Groq, Mistral AI e Ollama.

1

Google Gemini

O Google oferece acesso aos seus modelos Gemini avançados por meio do Google AI Studio. Eles oferecem um nível gratuito generoso para desenvolvedores. Observe que os modelos que podem ser usados gratuitamente são aqueles que contêm a palavra "lite" em seus nomes, como gemini-3.1-flash-lite ou gemini-flash-lite-latest.

  • Visite o site do Google AI Studio.
  • Faça login com sua conta do Google.
  • No menu de navegação do lado esquerdo, clique em "Obter chave de API".
  • Clique no botão "Criar chave de API". Você pode optar por criá-la em um projeto existente do Google Cloud ou permitir que o AI Studio crie uma nova para você.
  • Copie a chave gerada e cole na página de Opções do Analisador de Conteúdo, nas configurações do provedor Gemini.
2

OpenRouter.ai

O OpenRouter é uma interface unificada para múltiplos modelos de IA. Ele agrega modelos de vários provedores, e vários modelos de alta qualidade estão disponíveis completamente de graça.

  • Acesse a página inicial do OpenRouter.ai.
  • Cadastre-se ou faça login usando uma conta existente (Google, GitHub, etc.).
  • Uma vez logado, navegue até a seção "Chaves" no menu principal ou nas configurações da sua conta.
  • Clique em "Criar Chave". Dê a ela um nome como "Analisador de Conteúdo".
  • Copie sua nova chave de API. No Analisador de Conteúdo, selecione a opção de provedor OpenRouter, cole sua chave de API e selecione ou insira o ID do modelo escolhido (ex: google/gemini-2.5-flash:free).
3

Groq

O Groq fornece inferência extremamente rápida para modelos de IA de código aberto. Eles oferecem atualmente um nível gratuito com alto desempenho para desenvolvedores.

  • Visite o Console do Groq.
  • Cadastre-se ou faça login usando uma conta existente.
  • Navegue até a seção "Chaves de API" na barra lateral.
  • Clique em "Criar Chave de API" e dê a ela um nome descritivo.
  • Copie a chave de API gerada. No Analisador de Conteúdo, selecione a opção de provedor Groq, paste sua chave de API e selecione o modelo escolhido da lista (ex: llama-3.3-70b-versatile).
4

Mistral AI

A Mistral AI oferece acesso a modelos comerciais e de código aberto de última geração por meio do La Plateforme, oferecendo níveis gratuitos para desenvolvedores experimentarem.

  • Visite o Console da Mistral AI.
  • Cadastre-se ou faça login em sua conta.
  • Navegue até a seção "Chaves de API" na navegação do workspace.
  • Clique em "Criar nova chave" e copie a chave de API gerada.
  • No Analisador de Conteúdo, selecione a opção de provedor Mistral AI, cole sua chave de API e selecione o modelo escolhido da lista (ex: mistral-small-latest, mistral-large-latest, ou codestral-latest).
5

Ollama (ollama.com)

O Ollama fornece um serviço de API online permitindo que você se conecte diretamente a modelos hospedados por meio de sua plataforma web.

  • Visite o site Ollama.com.
  • Faça login em sua conta ou cadastre-se se ainda não tiver uma.
  • Clique no menu do usuário localizado no canto superior direito da página.
  • Selecione a opção "Configurações".
  • Selecione a seção "Chaves".
  • Clique em "Adicionar chave de API" e gere sua chave de API.
  • No Analisador de Conteúdo, escolha o tipo de API Ollama e defina a Base URL para https://ollama.com/, e insira o ID do modelo escolhido (ex: gemma4:31b).
