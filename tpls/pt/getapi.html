Extensão Analisador de Conteúdo

Obtenha uma Chave de API Gratuita

Para usar o Analisador de Conteúdo de forma eficaz, você precisará configurar um provedor de IA. Embora alguns provedores cobrem pelo uso, existem excelentes opções gratuitas disponíveis.

Abaixo, você encontrará instruções sobre como obter chaves de API gratuitas ou configurar serviços em plataformas populares: Google Gemini, OpenRouter, Groq, Mistral AI e Ollama.

1

Google Gemini

O Google oferece acesso aos seus avançados modelos Gemini por meio do Google AI Studio. Eles fornecem um plano gratuito generoso para desenvolvedores. Observe que os modelos que podem ser usados gratuitamente são aqueles que contêm a palavra "lite" em seu nome, como gemini-3.1-flash-lite ou gemini-flash-lite-latest.

  • Visite o site do Google AI Studio.
  • Faça login com sua conta Google.
  • No menu de navegação à esquerda, clique em "Obter chave de API".
  • Clique no botão "Criar chave de API". Você pode optar por criá-la em um projeto existente do Google Cloud ou permitir que o AI Studio crie um novo para você.
  • Copie a chave gerada e cole-a na página de Opções do Analisador de Conteúdo, nas configurações do provedor Gemini.
2

OpenRouter.ai

OpenRouter é uma interface unificada para vários modelos de IA. Ele agrega modelos de diversos provedores, e vários modelos de alta qualidade estão disponíveis gratuitamente.

  • Acesse a página inicial do OpenRouter.ai.
  • Inscreva-se ou faça login usando uma conta existente (Google, GitHub, etc.).
  • Depois de fazer login, navegue até a seção "Chaves" no menu principal ou nas configurações da sua conta.
  • Clique em "Criar chave". Dê um nome a ela, como "Analisador de Conteúdo".
  • Copie sua nova chave de API. No Analisador de Conteúdo, você pode usar essa chave selecionando a opção de compatibilidade com o OpenAI, definindo a URL base para https://openrouter.ai/api/v1 e inserindo o ID do modelo escolhido (por exemplo, google/gemini-2.5-flash:free).
3

Groq

Groq oferece inferência extremamente rápida para modelos de IA de código aberto. Atualmente, eles oferecem um plano gratuito com alto desempenho para desenvolvedores.

  • Visite o Console Groq.
  • Inscreva-se ou faça login usando uma conta existente.
  • Navegue até a seção "Chaves de API" na barra lateral.
  • Clique em "Criar chave de API" e dê um nome descritivo a ela.
  • Copie a chave de API gerada. No Analisador de Conteúdo, use a opção de compatibilidade com o OpenAI, defina a URL base para https://api.groq.com/openai/v1 e insira o ID do modelo escolhido (por exemplo, llama3-8b-8192).
4

Mistral AI

Mistral AI fornece acesso a modelos abertos e comerciais de última geração por meio do La Plateforme, oferecendo planos gratuitos para que os desenvolvedores experimentem.

  • Visite o Console Mistral AI.
  • Inscreva-se ou faça login em sua conta.
  • Navegue até a seção "Chaves de API" no menu de navegação do espaço de trabalho.
  • Clique em "Criar nova chave" e copie sua chave de API gerada.
  • No Analisador de Conteúdo, selecione a opção de compatibilidade com o OpenAI, defina a URL base para https://api.mistral.ai/v1 e insira o ID do modelo escolhido (por exemplo, mistral-small-latest).
5

Ollama (ollama.com)

Ollama fornece um serviço de API online que permite conectar diretamente a modelos hospedados por meio de sua plataforma web.

  • Visite o site Ollama.com.
  • Faça login em sua conta ou inscreva-se se ainda não tiver uma.
  • Clique no menu do usuário localizado no canto superior direito da página.
  • Selecione a opção "Configurações".
  • Selecione a seção "Chaves".
  • Clique em "Adicionar chave de API" e gere sua chave de API.
  • No Analisador de Conteúdo, escolha o tipo de API Ollama e defina a URL base para https://ollama.com/ e insira o ID do modelo escolhido (por exemplo, gemma4:31b).
