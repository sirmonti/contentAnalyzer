Analisador de Conteúdo

Política de Privacidade

Última Atualização: Abril de 2026

1. Introdução

A extensão do Chrome "contentAnalyzer" (a "Extensão") foi projetada para processar o conteúdo da página atual utilizando serviços de inteligência artificial configurados pelo usuário. Esta Política de Privacidade explica nosso compromisso com a sua privacidade e como os dados são tratados.

2. Nenhuma Coleta de Dados pelo Desenvolvedor

Valorizamos sua privacidade acima de tudo. O desenvolvedor desta Extensão não coleta, armazena ou transmite nenhum de seus dados pessoais, histórico de navegação ou conteúdo processado para qualquer servidor controlado pelo desenvolvedor.

Todas as configurações (como chaves de API ou prompts personalizados) são armazenadas localmente no armazenamento do seu navegador (ex: chrome.storage.local) e nunca ficam acessíveis ao desenvolvedor.

3. Transmissão de Dados para Serviços de Terceiros

Para fornecer sua funcionalidade principal, a Extensão envia o conteúdo da página que você escolhe analisar para o provedor de serviços de IA de terceiros (o "Serviço de IA") que você configurou nas definições.

3.1. Serviços Configurados pelo Usuário

A Extensão apenas se comunica com os endpoints/APIs específicos fornecidos pelo usuário. Como esses serviços são selecionados e configurados pelo usuário, o desenvolvedor do "contentAnalyzer" não tem controle sobre como esses sites de terceiros lidam com os dados enviados a eles.

3.2. Políticas de Privacidade de Terceiros

O desenvolvedor não pode ser responsabilizado pelas práticas de privacidade, políticas de retenção de dados ou medidas de segurança dos Serviços de IA que você escolher utilizar. Antes de usar a Extensão com um serviço específico, recomendamos fortemente que você revise a Política de Privacidade e os Termos de Serviço desse provedor.

4. Permissões

A Extensão requer permissões específicas para funcionar:

  • activeTab ou <all_urls>: Para ler o conteúdo da página que você deseja analisar.
  • storage: Para salvar sua configuração e configurações de API localmente.
  • permissões de host: Para enviar o conteúdo para a API do Serviço de IA que você especificou.

5. Segurança

Embora a Extensão facilite a transmissão de dados por meio de protocolos web padrão, a segurança dos dados após saírem do seu navegador depende inteiramente do Serviço de IA que você configurou. Recomendamos o uso de serviços que forneçam endpoints de API seguros (HTTPS).

6. Alterações nesta Política

O desenvolvedor reserva-se o direito de atualizar esta Política de Privacidade a qualquer momento. Quaisquer alterações serão refletidas em uma nova versão da Extensão e atualizadas nesta página.

7. Contato

Se você tiver alguma dúvida sobre esta Política de Privacidade, entre em contato com o desenvolvedor através dos canais de suporte fornecidos na página de Contato.
