内容分析器扩展

获取免费 API 密钥

为了有效使用内容分析器，您需要配置一个 AI 提供商。虽然一些提供商对其服务收取费用，但也有出色的免费选项可供选择。

以下是有关如何在流行的平台上获取免费 API 密钥或设置服务的说明：Google Gemini、OpenRouter、Groq、Mistral AI 和 Ollama。

1

Google Gemini

Google 通过 Google AI Studio 提供对其先进的 Gemini 模型的访问权限。他们为开发者提供慷慨的免费套餐。请注意，可以免费使用的模型是名称中包含“lite”一词的模型，例如 gemini-3.1-flash-lite 或 gemini-flash-lite-latest。

  • 访问 Google AI Studio 网站。
  • 使用您的 Google 帐户登录。
  • 在左侧导航菜单中，单击 “获取 API 密钥”。
  • 单击 “创建 API 密钥” 按钮。您可以选择将其创建到现有的 Google Cloud 项目中，或者让 AI Studio 为您创建一个新的项目。
  • 复制生成的密钥，并将其粘贴到内容分析器的选项页面中的 Gemini 提供程序设置下。
2

OpenRouter.ai

OpenRouter 是多个 AI 模型的统一接口。它聚合了来自各种提供商的模型，并且有几个高质量的模型完全可以免费使用。

  • 访问 OpenRouter.ai 主页。
  • 使用现有的帐户（Google、GitHub 等）注册或登录。
  • 登录后，从主菜单或您的帐户设置中导航到 “密钥” 部分。
  • 单击 “创建密钥”。为其命名，例如“内容分析器”。
  • 复制新的 API 密钥。在内容分析器中，您可以通过选择 OpenAI 兼容选项、将基本 URL 设置为 https://openrouter.ai/api/v1 以及输入您所选模型的 ID（例如 google/gemini-2.5-flash:free）来使用此密钥。
3

Groq

Groq 为开源 AI 模型提供极其快速的推理。他们目前为开发者提供具有高性能的免费套餐。

  • 访问 Groq 控制台。
  • 使用现有的帐户注册或登录。
  • 导航到侧边栏中的 “API 密钥” 部分。
  • 单击 “创建 API 密钥”，并为其指定一个描述性名称。
  • 复制生成的 API 密钥。在内容分析器中，使用 OpenAI 兼容选项，将基本 URL 设置为 https://api.groq.com/openai/v1，并输入您所选模型的 ID（例如 llama3-8b-8192）。
4

Mistral AI

Mistral AI 通过 La Plateforme 提供对最先进的开放和商业模型的访问权限，并为开发者提供免费套餐以进行实验。

  • 访问 Mistral AI 控制台。
  • 注册或登录您的帐户。
  • 从工作空间导航中，导航到 “API 密钥” 部分。
  • 单击 “创建新密钥” 并复制您生成的 API 密钥。
  • 在内容分析器中，选择 OpenAI 兼容选项，将基本 URL 设置为 https://api.mistral.ai/v1，并输入您所选的模型 ID（例如 mistral-small-latest）。
5

Ollama (ollama.com)Ollama 提供在线 API 服务，允许您直接连接到托管模型并通过其 Web 平台进行访问。

  • 访问 Ollama.com 网站。
  • 登录到您的帐户或注册（如果您还没有）。
  • 单击位于页面右上角的您的用户菜单。
  • 选择 “设置” 选项。
  • 选择 “密钥” 部分。
  • 单击 “添加 API 密钥” 并生成您的 API 密钥。
  • 在内容分析器中，选择 Ollama API 类型，并将基本 URL 设置为 https://ollama.com/，并输入您所选的模型 ID（例如 gemma4:31b）。
