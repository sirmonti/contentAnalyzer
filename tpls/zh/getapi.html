Content Analyzer Extension

获取免费 API 密钥

为了有效使用 Content Analyzer，您需要配置一个 AI 提供商。虽然一些提供商会收取使用费用，但也有一些非常优质的免费选择。

下方是关于如何获取免费 API 密钥或在热门平台上设置服务的说明：Google Gemini、OpenRouter、Groq、Mistral AI 和 Ollama。

1

Google Gemini

Google 通过 Google AI Studio 提供其高级 Gemini 模型的访问权限。他们为开发者提供非常慷慨的免费层。 请注意，可以免费使用的模型是名称中包含 "lite" 字样的模型，例如 gemini-3.1-flash-lite 或 gemini-flash-lite-latest。

  • 访问 Google AI Studio 网站。
  • 使用您的 Google 账户登录。
  • 在左侧导航菜单中，点击 "获取 API 密钥"。
  • 点击 "创建 API 密钥" 按钮。您可以选择在 现有的 Google Cloud 项目中创建，或者让 AI Studio 为您创建一个新项目。
  • 复制生成的密钥并将其粘贴到 Content Analyzer 的选项页面中 Gemini 提供商的设置下。
2

OpenRouter.ai

OpenRouter 是一个整合多种 AI 模型的统一界面。它整合了来自不同提供商的模型，并且有几个高质量 模型可以完全免费使用。

  • 前往 OpenRouter.ai 首页。
  • 使用现有账户（Google、GitHub 等）注册或登录。
  • 登录后，从主菜单或您的账户设置中导航至 "Keys" 区域。
  • 点击 "Create Key"。给它起一个名称，如 "Content Analyzer"。
  • 复制您的新 API 密钥。在 Content Analyzer 中，选择 OpenRouter 提供商选项，粘贴您的 API 密钥，并选择或输入您选择的模型 ID（例如， google/gemini-2.5-flash:free）。
3

Groq

Groq 为开源 AI 模型提供极速推理。他们目前为 开发人员提供性能出众的免费层。

  • 访问 Groq 控制台。
  • 使用现有账户注册或登录。
  • 在侧边栏中导航到 "API Keys" 区域。
  • 点击 "Create API Key" 并给它一个有描述性的名称。
  • 复制生成的 API 密钥。在 Content Analyzer 中，选择 Groq 提供商选项，粘贴您的 API 密钥，并从列表中选择您选定的模型（例如， llama-3.3-70b-versatile）。
4

Mistral AI

Mistral AI 通过 La Plateforme 提供最先进的开源和商业模型，并为 开发者提供免费层供其进行实验。

  • 访问 Mistral AI 控制台。
  • 登录或注册您的账户。
  • 从工作空间导航中导航到 "API Keys" 区域。
  • 点击 "Create new key" 并复制生成的 API 密钥。
  • 在 Content Analyzer 中，选择 Mistral AI 提供商选项， 粘贴您的 API 密钥，并从列表中选择您选定的模型（例如， mistral-small-latest，mistral-large-latest，或 codestral-latest）。
5

Ollama (ollama.com)

Ollama 提供一种在线 API 服务，允许您通过他们的 Web 平台直接连接到托管模型。

  • 访问 Ollama.com 网站。
  • 登录您的账户，如果您还没有账户，请注册。
  • 点击位于页面右上角的用户菜单。
  • 选择 "Settings" 选项。
  • 选择 "Keys" 区域。
  • 点击 "Add API key" 并生成您的 API 密钥。
  • 在 Content Analyzer 中，选择 Ollama API 类型，并 将基础 URL 设置为 https://ollama.com/，并输入您选择的模型 ID（例如， gemma4:31b）。
