内容分析器扩展

使用与配置指南

内容分析器是一款旨在自动提取和评估复杂网络环境中语义元数据的浏览器扩展。该扩展可支持在 Firefox、Chrome 以及基于 Chromium 的浏览器上运行，其核心目的是通过将内容传递到各种人工智能（AI）服务来处理网页内容。

与普通的网页摘要工具不同，此扩展允许您创建多个自定义 AI 服务，每个服务都具有高度特定的提示词，用以规定 AI 应如何处理收集到的信息。您可以使用它来提取代码、翻译特定术语、分析情感、生成针对性报告等。

主要功能

  • 自定义内容抓取： 您可以使用交互式“悬停工具”轻松选择网页的特定部分，或者选择抓取整个页面内容。
  • 多个自定义 AI 提示词和系统提示词： 根据您的具体需求创建不同的服务，并配有自定义用户提示词和可选的系统提示词（例如，“总结文章”、“提取 JSON 数据”、“翻译成西班牙语”、自定义助手角色等）。
  • 特定领域的服务： 您可以将自定义服务链接到特定的 Web 域名。这有助于保持扩展程序的整洁，因为它仅显示相关的 AI 工具。
  • 广泛的 LLM 兼容性： 完全支持通过 Ollama 与本地服务器连接（包括文本流传输），同时也支持 Anthropic (Claude)、Google Gemini、Groq、OpenRouter、Mistral AI 和 OpenAI 等云端 API 提供商。
2

支持的 AI 供应商

该扩展旨在高度灵活，允许您连接到多种行业领先的人工智能模型和本地服务。目前支持：

  • Claude (Anthropic)： 通过其官方 API 访问功能强大的 Claude 系列模型。
  • Gemini (Google)： 直接连接到 Google 的先进 Gemini 模型。
  • Groq： 配备专门的 Llama、Mixtral 和 Gemma 模型，提供超快速推理。
  • OpenRouter： 提供统一访问来自多个提供商的大量 AI 模型目录。
  • Mistral AI： 通过官方 API 连接到最先进的开源和商业 Mistral 模型。
  • ChatGPT (OpenAI 及兼容款)： 完全兼容 OpenAI 的 API，以及任何其他提供兼容 OpenAI 端点的第三方服务。
  • Ollama (或兼容款)： 在您自己的机器上本地且私密地运行模型，无需将数据发送到云端。
3

提示词动态标签

为了让您的 AI 提示词更具上下文相关性和更强大，您可以在用户提示词和系统提示词中利用以下动态标签。扩展程序将在将提示词发送给 AI 模型之前自动替换这些内容：

标签 描述
{DATE} 使用您本地格式的当前日期进行替换。
{HOUR} 使用您本地格式的当前时间进行替换。
{URL} 当前正在处理的网页的完整 URL。
{DOMAIN} 正在处理的网页的根域名。
{LANG} 网页的语言。
{SYSLANG} 当前系统/浏览器的语言配置。
{TITLE} 当前正在处理的网页的 HTML 标题。
4

配置示例

以下是一些展示如何构建您服务的示例：

示例 1：多语言翻译助手

服务名称： 翻译到本地语言
链接的域名： (空 - 在任何地方可用)

请扮演一名专业翻译员。我正在访问一个位于 {URL} 的 {LANG} 语言网站，但我的浏览器设置是 {SYSLANG}。请将以下内容准确翻译成 {SYSLANG}，并保持原始的 Markdown 和文本格式。

示例 2：代码审查（特定领域）

服务名称： Python 代码审查
链接的域名： github.com, gitlab.com, stackoverflow.com

你是一位资深开发者。以下提供的代码片段是在 {DOMAIN} 上找到的。请严格审查代码中的潜在错误、安全漏洞和代码异味。不要解释代码的功能，只需列出问题并提供修复后的版本。

示例 3：每日简报提取器

服务名称： 提取关键实体
链接的域名： news.ycombinator.com, techcrunch.com, bbc.com

今天是 {DATE} 的 {HOUR}。请扫描以下新闻文章，并提取一份整齐的 JSON 列表，包含文中提到的主要“人物”、“组织”和“地点”。

示例 4：自定义助理角色（系统提示词）

服务名称： Mario 助手
系统提示词：

你是 Mario，一位聪明且敏锐的助手，你的工作是尽可能高效地完成分配给你的任务。在涉及时间参考的任务中，你必须记住今天是 {DATE}。

用户提示词：

请分析从 {URL} 获取的以下文本，并提供主要观点的摘要。

浏览器安装

安装过程可以通过官方仓库完成，或者通过在开发者模式下加载未打包的包来完成。

  • Google Chrome： 从 Chrome Web Store 下载。
  • Mozilla Firefox： 从 Firefox Add-ons 下载。
  • 或者，您可以通过 chrome://extensions/ 或 about:debugging 在开发者模式下加载未打包的扩展。
info
注意： 在运行任何抓取之前，请确保您已在扩展的“选项”页面中正确配置了全局设置（API 密钥或本地 Ollama 实例）。
