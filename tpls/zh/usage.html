内容分析器扩展程序

使用和配置指南

内容分析器是一款浏览器扩展程序，旨在在复杂的网络环境中自动提取和评估语义元数据。该扩展程序适用于 Firefox、Chrome 和基于 Chromium 的浏览器，其核心目的是通过各种人工智能 (AI) 服务来处理网页内容。

与其他典型的网页摘要工具不同，此扩展程序允许您创建多个自定义 AI 服务，每个服务都具有高度特定的提示，以准确地指示 AI 如何处理收集到的信息。您可以使用它来提取代码、翻译特定术语、分析情感、生成有针对性的报告等等。

主要功能

  • 自定义内容捕获： 您可以使用交互式“悬停工具”轻松选择网页的特定部分，或者可以选择捕获整个页面内容。
  • 多个自定义 AI 提示和系统提示： 创建针对您确切需求的各种服务，并使用自定义用户提示以及可选的系统提示（例如，“总结文章”、“提取 JSON 数据”、“翻译成西班牙语”、“自定义助手角色”等）。
  • 特定领域的服务： 您可以将自定义服务链接到特定的网站域。这有助于保持扩展程序的整洁性，仅显示相关的 AI 工具。
  • 广泛的 LLM 兼容性： 完全支持通过 Ollama 与本地服务器（包括文本流）的连接，以及与 OpenAI、Anthropic 和 Google Gemini 等云 API 提供商的连接。
2

支持的 AI 提供商

此扩展程序的设计具有高度灵活性，允许您连接到各种领先的人工智能模型和本地服务。目前，它支持：

  • Claude (Anthropic)： 通过其官方 API 访问功能强大的 Claude 模型系列。
  • Gemini (Google)： 直接连接到 Google 的先进 Gemini 模型。
  • ChatGPT (OpenAI 和兼容服务)： 完全兼容 OpenAI 的 API，以及任何提供与 OpenAI 兼容端点的其他第三方服务。
  • Ollama： 在您自己的机器上本地且私密地运行模型，而无需将数据发送到云端。
3

动态提示标签

为了使您的 AI 提示更具上下文意义和强大的功能，您可以在用户提示和系统提示中利用以下动态标签。扩展程序将在将提示发送到 AI 模型之前自动替换它们：

标签 描述
{DATE} 替换为您本地格式的当前日期。
{HOUR} 替换为您本地格式的当前时间。
{URL} 当前正在处理的网页的完整 URL。
{DOMAIN} 正在处理的网页的根域名。
{LANG} 网页的语言。
{SYSLANG} 当前的系统/浏览器语言配置。
4

示例配置

以下是一些演示如何构建服务的示例：

示例 1：多语言翻译助手

服务名称： 翻译成本地语言
链接的域： (为空 - 在所有地方可用)

我正在浏览一个 {LANG} 语言的网站，网址为 {URL}，但我的浏览器设置为 {SYSLANG}。请准确地将以下内容翻译成 {SYSLANG}，并保留原始的 Markdown 和文本格式。

示例 2：代码审查器（特定领域）

服务名称： Python 代码审查
链接的域： github.com、gitlab.com、stackoverflow.com

您是一位专业的开发人员。以下代码片段来自 {DOMAIN}。严格分析代码，查找潜在的错误、安全漏洞和代码风格问题。不要解释代码的作用，只需列出问题并提供更正后的版本。

示例 3：每日简报提取器

服务名称： 提取关键实体
链接的域： news.ycombinator.com、techcrunch.com、bbc.com

今天是 {DATE}，时间为 {HOUR}。扫描以下新闻文章并提取一个整洁的 JSON 列表，其中包含文本中提到的主要“人物”、“组织”和“地点”。

示例 4：自定义助手角色（系统提示）

服务名称： Mario 助手
系统提示：

你是马里奥，一个聪明且高效的助手，你的工作是以尽可能有效的方式完成分配给你的任务。在涉及时间参考的任务中，您必须记住今天是 {DATE}。

用户提示：

分析从 {URL} 捕获的以下文本，并提供主要内容的摘要。
5

浏览器安装

安装过程是通过官方存储库或通过以开发模式加载未打包的扩展程序来完成。

  • Google Chrome： 从 Chrome 网上应用店下载。
  • Mozilla Firefox： 从 Firefox 插件商店下载。
  • 或者，您可以通过 chrome://extensions/ 或 about:debugging 以开发模式加载未打包的扩展程序。
info
注意： 请确保您已正确配置全局设置（API 密钥或本地 Ollama 实例），在扩展程序的选项页面中，然后再运行任何捕获。
