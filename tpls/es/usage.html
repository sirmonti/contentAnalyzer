Extensión de Content Analyzer

Guía de Uso y Configuración

El Content Analyzer es una extensión de navegador diseñada para la extracción y evaluación automatizada de metadatos semánticos en entornos web complejos. Esta extensión funciona en Firefox, Chrome y navegadores derivados de Chromium; su propósito principal es procesar contenido web pasándolo a través de diversos servicios de Inteligencia Artificial (IA).

A diferencia de los resumidores de páginas web habituales, esta extensión le permite crear múltiples servicios de IA personalizados, cada uno con un prompt altamente específico que dicta exactamente qué debe hacer la IA con la información recopilada. Puede utilizarla para extraer código, traducir términos específicos, analizar sentimientos, generar informes específicos y mucho más.

Características Principales

  • Captura de Contenido Personalizado: Puede seleccionar fácilmente una parte específica de una página web mediante una "herramienta de selección" interactiva, o elegir capturar el contenido de la página completa.
  • Múltiples Prompts de IA y Prompts de Sistema Personalizados: Cree diferentes servicios adaptados a sus necesidades exactas con prompts de usuario personalizados y Prompts de Sistema opcionales (ej., "Resumir artículo", "Extraer datos JSON", "Traducir al español", personalidades de asistente personalizadas, etc.).
  • Servicio por Dominio Específico: Puede vincular sus servicios personalizados a dominios web específicos. Esto ayuda a mantener su extensión limpia, mostrando solo las herramientas de IA relevantes.
  • Amplia Compatibilidad con LLM: Soporta plenamente conexiones (incluido el flujo de texto) con servidores locales a través de Ollama, así como proveedores de API en la nube como Anthropic (Claude), Google Gemini, Groq, OpenRouter, Mistral AI y OpenAI.
2

Proveedores de IA Soportados

Esta extensión está diseñada para ser altamente flexible, permitiéndole conectarse a una variedad de modelos de Inteligencia Artificial líderes en la industria y servicios locales. Actualmente, es compatible con:

  • Claude (Anthropic): Acceda a la potente familia de modelos Claude a través de su API oficial.
  • Gemini (Google): Conéctese directamente a los avanzados modelos Gemini de Google.
  • Groq: Inferencia ultrarrápida con modelos dedicados Llama, Mixtral y Gemma.
  • OpenRouter: Acceso unificado a un vasto catálogo de modelos de IA de múltiples proveedores.
  • Mistral AI: Conéctese a los modelos Mistral de código abierto y comerciales de última generación a través de su API oficial.
  • ChatGPT (OpenAI y compatibles): Totalmente compatible con la API de OpenAI, así como con cualquier otro servicio de terceros que ofrezca un punto de conexión compatible con OpenAI.
  • Ollama (o compatibles): Ejecute modelos de forma local y privada en su propio equipo sin enviar datos a la nube.

Etiquetas Dinámicas de Prompts

Para que sus prompts de IA sean más contextuales y potentes, puede utilizar las siguientes etiquetas dinámicas tanto en los prompts de usuario como en los Prompts de Sistema. La extensión los sustituirá automáticamente antes de enviar el prompt al modelo de IA:

Etiqueta Descripción
{DATE} Reemplazado por la fecha actual en su formato local.
{HOUR} Reemplazado por la hora actual en su formato local.
{URL} La URL completa de la página web que se está procesando actualmente.
{DOMAIN} El dominio raíz de la página web que se está procesando.
{LANG} El idioma de la página web.
{SYSLANG} La configuración actual del idioma del sistema/navegador.
{TITLE} El título HTML de la página web que se está procesando actualmente.

Configuraciones de Ejemplo

A continuación se muestran algunos ejemplos de cómo puede estructurar sus servicios:

Ejemplo 1: Asistente de Traducción Multilingüe

Nombre del servicio: Traducir al idioma local
Dominios vinculados: (Vacío - Disponible en todas partes)

Actúe como un traductor profesional. Estoy navegando en un sitio en el idioma {LANG} en {URL}, pero mi navegador está configurado en {SYSLANG}. Por favor, traduzca con precisión el siguiente contenido a {SYSLANG}, manteniendo intacto el formato original de markdown y de texto.

Ejemplo 2: Revisor de Código (Dominio Específico)

Nombre del servicio: Revisión de Código en Python
Dominios vinculados: github.com, gitlab.com, stackoverflow.com

Usted es un desarrollador experto. Los fragmentos de código proporcionados a continuación se encontraron en {DOMAIN}. Analice el código estrictamente en busca de posibles errores, vulnerabilidades de seguridad y "code smells". No explique qué hace el código, solo enumere los problemas y proporcione una versión corregida.

Ejemplo 3: Extractor de Resumen Diario

Nombre del servicio: Extraer Entidades Clave
Dominios vinculados: news.ycombinator.com, techcrunch.com, bbc.com

Hoy es {DATE} a las {HOUR}. Escanee el siguiente artículo de noticias y extraiga una lista JSON estructurada que contenga las principales "Personas", "Organizaciones" y "Lugares" mencionados en el texto.

Ejemplo 4: Persona de Asistente Personalizada (Prompt de Sistema)

Nombre del servicio: Asistente Mario
Prompt de Sistema:

Usted es Mario, un asistente ingenioso y perspicaz; su trabajo es cumplir las tareas que se le asignen de la manera más eficiente posible. En las tareas que tengan referencias temporales, debe tener en cuenta que hoy es {DATE}

Prompt de usuario:

Analice el siguiente texto capturado de {URL} y proporcione un resumen de los puntos principales.

Instalación en el Navegador

El proceso de instalación se realiza a través del repositorio oficial o cargando el paquete sin empaquetar en modo de desarrollador.

  • Google Chrome: Descargar desde Chrome Web Store.
  • Mozilla Firefox: Descargar desde Firefox Add-ons.
  • Alternativamente, puede cargar la extensión sin empaquetar en modo de desarrollador a través de chrome://extensions/ o about:debugging.
info
Nota: Asegúrese de haber configurado correctamente los ajustes globales (Claves API o instancias locales de Ollama) en la página de Opciones de la extensión antes de realizar cualquier captura.
