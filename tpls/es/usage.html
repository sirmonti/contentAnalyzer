Extensión Analizador de Contenido

Guía de Uso y Configuración

El Analizador de Contenido es una extensión de navegador diseñada para la extracción y evaluación automatizada de metadatos semánticos en entornos web complejos. Esta extensión funciona en Firefox, Chrome y navegadores derivados de Chromium, y su propósito principal es procesar el contenido web pasándolo a través de varios servicios de Inteligencia Artificial (IA).

A diferencia de los resumidores de páginas web típicos, esta extensión le permite crear múltiples servicios de IA personalizados, cada uno con una instrucción muy específica que dicta exactamente qué debe hacer la IA con la información recopilada. Puede utilizarla para extraer código, traducir términos específicos, analizar el sentimiento, generar informes específicos y mucho más.

Características Principales

  • Captura de Contenido Personalizada: Puede seleccionar fácilmente una parte específica de una página web utilizando una "herramienta interactiva", u optar por capturar todo el contenido de la página.
  • Múltiples Instrucciones y Instrucciones de Sistema de IA Personalizadas: Cree diferentes servicios adaptados a sus necesidades exactas con instrucciones de usuario personalizadas e instrucciones de sistema opcionales (por ejemplo, "Resumir artículo", "Extraer datos JSON", "Traducir al español", personalidades de asistente personalizadas, etc.).
  • Servicios Específicos de Dominio: Puede vincular sus servicios personalizados a dominios web específicos. Esto ayuda a mantener su extensión organizada al mostrar solo las herramientas de IA relevantes.
  • Amplia Compatibilidad con LLM: Admite completamente las conexiones (incluido el streaming de texto) con servidores locales a través de Ollama, así como proveedores de API en la nube como OpenAI, Anthropic y Google Gemini.
2

Proveedores de IA Soportados

Esta extensión está diseñada para ser altamente flexible, lo que le permite conectarse a una variedad de modelos de Inteligencia Artificial líderes en la industria y servicios locales. Actualmente, admite:

  • Claude (Anthropic): Acceda a la potente familia de modelos Claude a través de su API oficial.
  • Gemini (Google): Conéctese directamente a los avanzados modelos Gemini de Google.
  • ChatGPT (OpenAI y compatibles): Totalmente compatible con la API de OpenAI, así como con cualquier otro servicio de terceros que ofrezca un extremo compatible con OpenAI.
  • Ollama: Ejecute modelos localmente y de forma privada en su propia máquina sin enviar datos a la nube.
3

Etiquetas Dinámicas de Instrucción

Para que sus instrucciones de IA sean más contextuales y potentes, puede utilizar las siguientes etiquetas dinámicas tanto en las instrucciones de usuario como en las instrucciones del sistema. La extensión sustituirá automáticamente estas etiquetas antes de enviar la instrucción al modelo de IA:

Etiqueta Descripción
{DATE} Se reemplaza por la fecha actual en su formato local.
{HOUR} Se reemplaza por la hora actual en su formato local.
{URL} La URL completa de la página web que se está procesando.
{DOMAIN} El dominio raíz de la página web que se está procesando.
{LANG} El idioma de la página web.
{SYSLANG} La configuración de idioma actual del sistema/navegador.
{TITLE} El título HTML de la página web que se está procesando.

Ejemplos de Configuraciones

A continuación, se muestran algunos ejemplos que ilustran cómo puede estructurar sus servicios:

Ejemplo 1: Asistente de Traducción Multilingüe

Nombre del servicio: Traducir al idioma local
Dominios vinculados: (Vacío - Disponible en todas partes)

Actúa como un traductor profesional. Estoy navegando por un sitio en el idioma {LANG} en {URL}, pero mi navegador está configurado en {SYSLANG}. Traduzca con precisión el siguiente contenido al {SYSLANG}, manteniendo el formato de texto y Markdown original.

Ejemplo 2: Analizador de Código (Específico del dominio)

Nombre del servicio: Revisión de código Python
Dominios vinculados: github.com, gitlab.com, stackoverflow.com

Es un desarrollador experto. Los fragmentos de código proporcionados a continuación se encontraron en {DOMAIN}. Analice el código estrictamente para detectar posibles errores, vulnerabilidades de seguridad y código con problemas. No explique lo que hace el código, simplemente enumere los problemas y proporcione una versión corregida.

Ejemplo 3: Extractor de Resumen Diario

Nombre del servicio: Extraer Entidades Clave
Dominios vinculados: news.ycombinator.com, techcrunch.com, bbc.com

Hoy es {DATE} a las {HOUR}. Analice el siguiente artículo y extraiga una lista JSON ordenada que contenga las principales "Personas", "Organizaciones" y "Ubicaciones" mencionadas en el texto.

Ejemplo 4: Personalidad de Asistente Personalizada (Instrucción del Sistema)

Nombre del servicio: Asistente Mario
Instrucción del sistema:

Eres Mario, un asistente inteligente y perspicaz, tu trabajo es cumplir con las tareas asignadas de la manera más eficiente posible. En las tareas que tienen referencias temporales, debe tener en cuenta que hoy es {DATE}.

Instrucción del usuario:

Analice el siguiente texto capturado de {URL} y proporcione un resumen de los puntos principales.

Instalación en el Navegador

El proceso de instalación se realiza a través del repositorio oficial o cargando el paquete sin comprimir en modo de desarrollador.

  • Google Chrome: Descargar desde Chrome Web Store.
  • Mozilla Firefox: Descargar desde Complementos de Firefox.
  • Alternativamente, puede cargar la extensión sin comprimir en modo de desarrollador a través de chrome://extensions/ o about:debugging.
info
Nota: Asegúrese de haber configurado correctamente la configuración global (claves de API o instancias de Ollama locales) en la página de Opciones de la extensión antes de ejecutar cualquier captura.
