Extensión de Análisis de Contenido

Guía de Uso y Configuración

El Analizador de Contenido es una extensión de navegador diseñada para la extracción y evaluación automatizada de metadatos semánticos en entornos web complejos. Esta extensión funciona en Firefox, Chrome y navegadores derivados de Chromium; su propósito principal es procesar el contenido web pasándolo a través de varios servicios de Inteligencia Artificial (IA).

A diferencia de los resumidores de páginas web típicos, esta extensión le permite crear múltiples servicios de IA personalizados, cada uno con una instrucción específica que dicta exactamente qué debe hacer la IA con la información recopilada. Puede utilizarla para extraer código, traducir términos específicos, analizar el sentimiento, generar informes dirigidos y mucho más.

Características Principales

  • Captura de Contenido Personalizada: Puede seleccionar fácilmente una parte específica de una página web utilizando una "herramienta interactiva" o optar por capturar todo el contenido de la página.
  • Múltiples Instrucciones y Instrucciones del Sistema de IA Personalizadas: Cree diferentes servicios adaptados a sus necesidades exactas con instrucciones de usuario personalizadas e instrucciones del sistema opcionales (por ejemplo, "Resumir artículo", "Extraer datos JSON", "Traducir al español", personalidades de asistente personalizadas, etc.).
  • Servicio Específico del Dominio: Puede vincular sus servicios personalizados a dominios web específicos. Esto ayuda a mantener su extensión organizada mostrando solo las herramientas de IA relevantes.
  • Amplia Compatibilidad con LLM: Admite completamente las conexiones (incluida la transmisión de texto) con servidores locales a través de Ollama, así como proveedores de API en la nube como OpenAI, Anthropic y Google Gemini.
2

Proveedores de IA Soportados

Esta extensión está diseñada para ser muy flexible, lo que le permite conectarse a una variedad de modelos de Inteligencia Artificial líderes en la industria y servicios locales. Actualmente, admite:

  • Claude (Anthropic): Acceda a la potente familia de modelos Claude a través de su API oficial.
  • Gemini (Google): Conéctese directamente a los avanzados modelos Gemini de Google.
  • ChatGPT (OpenAI y compatibles): Totalmente compatible con la API de OpenAI, así como con cualquier otro servicio de terceros que ofrezca un punto final compatible con OpenAI.
  • Ollama: Ejecute modelos localmente y de forma privada en su propia máquina sin enviar datos a la nube.
3

Etiquetas Dinámicas para Instrucciones

Para que sus instrucciones de IA sean más contextuales y potentes, puede utilizar las siguientes etiquetas dinámicas tanto en las instrucciones del usuario como en las instrucciones del sistema. La extensión sustituirá automáticamente estas etiquetas antes de enviar la instrucción al modelo de IA:

Etiqueta Descripción
{DATE} Se reemplaza por la fecha actual en su formato local.
{HOUR} Se reemplaza por la hora actual en su formato local.
{URL} La URL completa de la página web que se está procesando.
{DOMAIN} El dominio raíz de la página web que se está procesando.
{LANG} El idioma de la página web.
{SYSLANG} La configuración de idioma actual del sistema/navegador.

Ejemplos de Configuraciones

A continuación, se muestran algunos ejemplos que ilustran cómo puede estructurar sus servicios:

Ejemplo 1: Asistente de Traducción Multilingüe

Nombre del servicio: Traducir al idioma local
Dominios vinculados: (Vacío - Disponible en todas partes)

Actúa como un traductor profesional. Estoy navegando por un sitio en el idioma {LANG} en {URL}, pero mi navegador está configurado en {SYSLANG}. Por favor, traduce con precisión el siguiente contenido a {SYSLANG}, manteniendo la maquetación y el formato de texto originales.

Ejemplo 2: Analizador de Código (Específico del Dominio)

Nombre del servicio: Revisión de código Python
Dominios vinculados: github.com, gitlab.com, stackoverflow.com

Eres un desarrollador experto. Los fragmentos de código que se proporcionan a continuación se encontraron en {DOMAIN}. Analiza el código estrictamente para detectar posibles errores, vulnerabilidades de seguridad y problemas de calidad del código. No expliques lo que hace el código, simplemente enumera los problemas y proporciona una versión corregida.

Ejemplo 3: Extractor de Información Diaria

Nombre del servicio: Extraer Entidades Clave
Dominios vinculados: news.ycombinator.com, techcrunch.com, bbc.com

Hoy es {DATE} a las {HOUR}. Analiza el siguiente artículo de noticias y extrae una lista JSON ordenada que contenga las principales "Personas", "Organizaciones" y "Ubicaciones" mencionadas en el texto.

Ejemplo 4: Persona de Asistente Personalizada (Instrucción del Sistema)

Nombre del servicio: Asistente Mario
Instrucción del sistema:

Eres Mario, un asistente inteligente y astuto. Tu trabajo es realizar las tareas que se te asignen de la manera más eficiente posible. En las tareas que tienen referencias temporales, debes tener en cuenta que hoy es {DATE}.

Instrucción del usuario:

Analiza el siguiente texto capturado de {URL} y proporciona un resumen de los puntos principales.

Instalación en el Navegador

El proceso de instalación se realiza a través del repositorio oficial o cargando el paquete sin empaquetar en modo de desarrollador.

  • Google Chrome: Descargar de Chrome Web Store.
  • Mozilla Firefox: Descargar de Complementos de Firefox.
  • Alternativamente, puede cargar la extensión sin empaquetar en modo de desarrollador a través de chrome://extensions/ o about:debugging.
info
Nota: Asegúrese de haber configurado correctamente la configuración global (claves API o instancias locales de Ollama) en la página de Opciones de la extensión antes de ejecutar cualquier captura.
