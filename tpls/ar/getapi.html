الحصول على مفتاح API مجاني

لاستخدام بفعالية، ستحتاج إلى إعداد مزود ذكاء اصطناعي. في حين أن بعض المزودين يفرضون رسومًا على استخدامهم، إلا أن هناك خيارات مجانية ممتازة متاحة.

ستجد أدناه تعليمات حول كيفية الحصول على مفاتيح API مجانية أو إعداد الخدمات عبر المنصات الشهيرة: Google Gemini، وOpenRouter، وGroq، وMistral AI، وOllama.

1

Google Gemini

توفر جوجل إمكانية الوصول إلى نماذج Gemini المتقدمة عبر Google AI Studio. توفر الشركة فئة مجانية سخية للمطورين. لاحظ أن النماذج التي يمكن استخدامها مجانًا هي تلك التي تحتوي على كلمة "lite" في اسمها، مثل gemini-3.1-flash-lite أو gemini-flash-lite-latest.

  • قم بزيارة موقع Google AI Studio.
  • سجل الدخول باستخدام حساب Google الخاص بك.
  • في قائمة التنقل على الجانب الأيسر، انقر فوق "الحصول على مفتاح API".
  • انقر فوق زر "إنشاء مفتاح API". يمكنك اختيار إنشائه في مشروع Google Cloud موجود أو السماح لـ AI Studio بإنشاء واحد جديد لك.
  • انسخ المفتاح الذي تم إنشاؤه وألصقه في صفحة الخيارات في "محلل المحتوى" تحت إعدادات مزود Gemini.
2

OpenRouter.ai

يعد OpenRouter واجهة موحدة لعدة نماذج ذكاء اصطناعي. فهو يجمع بين نماذج من مزودين مختلفين، وتتوفر العديد من النماذج عالية الجودة مجانًا تمامًا.

  • انتقل إلى الصفحة الرئيسية لـ OpenRouter.ai.
  • قم بالتسجيل أو تسجيل الدخول باستخدام حساب موجود (Google، GitHub، إلخ).
  • بمجرد تسجيل الدخول، انتقل إلى قسم "Keys" من القائمة الرئيسية أو إعدادات حسابك.
  • انقر فوق "Create Key". أعطه اسمًا مثل "Content Analyzer".
  • انسخ مفتاح API الجديد الخاص بك. في "محلل المحتوى"، اختر خيار مزود OpenRouter، وألصق مفتاح API الخاص بك، ثم اختر أو أدخل معرف النموذج الذي اخترته (على سبيل المثال، google/gemini-2.5-flash:free).
3

Groq

توفر Groq استدلالًا سريعًا للغاية لنماذج الذكاء الاصطناعي مفتوحة المصدر. وهي تقدم حاليًا فئة مجانية ذات أداء عالٍ للمطورين.

  • قم بزيارة Groq Console.
  • قم بالتسجيل أو تسجيل الدخول باستخدام حساب موجود.
  • انتقل إلى قسم "API Keys" في الشريط الجانبي.
  • انقر فوق "Create API Key" وأعطه اسمًا وصفيًا.
  • انسخ مفتاح API الذي تم إنشاؤه. في "محلل المحتوى"، اختر خيار مزود Groq، وألصق مفتاح API الخاص بك، واختر نموذجك المفضل من القائمة (على سبيل المثال، llama-3.3-70b-versatile).
4

Mistral AI

توفر Mistral AI إمكانية الوصول إلى نماذج مفتوحة وتجارية متطورة عبر La Plateforme، مع توفير مستويات مجانية للمطورين للتجربة.

  • قم بزيارة Mistral AI Console.
  • قم بالتسجيل أو تسجيل الدخول إلى حسابك.
  • انتقل إلى قسم "API Keys" من تنقل مساحة العمل.
  • انقر فوق "Create new key" وانسخ مفتاح API الذي تم إنشاؤه.
  • في "محلل المحتوى"، اختر خيار مزود Mistral AI، وألصق مفتاح API الخاص بك، واختر النموذج الذي اخترته من القائمة (على سبيل المثال، mistral-small-latest، أو mistral-large-latest، أو codestral-latest).
5

Ollama (ollama.com)

توفر Ollama خدمة API عبر الإنترنت تتيح لك الاتصال مباشرة بالنماذج المستضافة عبر منصتهم على الويب.

  • قم بزيارة موقع Ollama.com.
  • سجل الدخول إلى حسابك أو قم بالتسجيل إذا لم يكن لديك حساب بعد.
  • انقر على قائمة المستخدم الموجودة في الزاوية العلوية اليمنى من الصفحة.
  • اختر خيار "Settings".
  • اختر قسم "Keys".
  • انقر فوق "Add API key" وقم بإنشاء مفتاح API الخاص بك.
  • في "محلل المحتوى"، اختر نوع واجهة برمجة التطبيقات (API) لـ Ollama واضبط رابط الأساس (Base URL) على https://ollama.com/، وأدخل معرف النموذج الذي اخترته (على سبيل المثال، gemma4:31b).
