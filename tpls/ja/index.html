コンテンツアナライザー - Webブラウザ拡張機能

知的な分析を重視して設計された拡張機能です。ブラウザを構造化された分析環境に変換し、あらゆるWebテキストをリアルタイムで分解、分類、メタデータを抽出できます。

download Chrome版をインストール download Firefox版をインストール code GitHubで確認

主な機能

bolt

リアルタイム分析

大きなドキュメントを瞬時に処理します。このツールは、表示されているDOMをスキャンし、ページを再読み込みすることなく解析アルゴリズムを適用し、読書に集中できるようにします。

database

メタデータ抽出

  • 書誌的引用の抽出。
  • 主要なエンティティの識別。
  • 数値データの表形式での構成。
design_services

アカデミックなインターフェース

集中力と視覚的な持続性を重視して設計されています。ニュートラルなカラーパレット、読みやすいタイポグラフィ、気を散らすアニメーションや余分な要素を一切排除しています。
