コンテンツアナライザー拡張機能

使用方法と設定ガイド

コンテンツアナライザーは、複雑なウェブ環境でセマンティックメタデータの自動抽出および評価を行うように設計されたブラウザ拡張機能です。この拡張機能は、Firefox、Chrome、および Chromium ベースのブラウザで動作し、その主な目的は、さまざまな人工知能（AI）サービスを通じてウェブコンテンツを処理することです。

一般的なウェブページ要約ツールとは異なり、この拡張機能では、複数のカスタム AI サービスを作成でき、それぞれのサービスに高度に特化したプロンプトを設定することで、収集された情報に対して AI が正確に行うべきことを指示できます。これを使用して、コードの抽出、特定の用語の翻訳、感情分析、ターゲットを絞ったレポートの生成などを行うことができます。

主な機能

  • カスタムコンテンツのキャプチャ: インタラクティブな「ホバーツール」を使用してウェブページの特定の部分を選択したり、ページ全体のコンテンツをキャプチャすることを選択できます。
  • 複数のカスタム AI プロンプトとシステムプロンプト: カスタムユーザープロンプトとオプションのシステムプロンプト（例：「記事の要約」、「JSON データの抽出」、「スペイン語への翻訳」、カスタムアシスタントのペルソナなど）を使用して、ニーズに合わせて調整されたさまざまなサービスを作成できます。
  • ドメイン固有のサービス: カスタムサービスを特定のウェブドメインに関連付けることができます。これにより、関連する AI ツールのみを表示することで、拡張機能を整理できます。
  • 広範な LLM の互換性: Ollama を介したローカルサーバーとの接続（テキストストリーミングを含む）や、OpenAI、Anthropic、Google Gemini などのクラウド API プロバイダーとの完全な互換性をサポートします。
2

サポートされている AI プロバイダー

この拡張機能は、業界をリードするさまざまな人工知能モデルおよびローカルサービスに接続できるように、高度な柔軟性を備えて設計されています。現在、以下のプロバイダーをサポートしています。

  • Claude (Anthropic): Anthropic の公式 API を介して強力な Claude ファミリーモデルにアクセスできます。
  • Gemini (Google): Google の高度な Gemini モデルに直接接続できます。
  • ChatGPT (OpenAI & 互換性のあるもの): OpenAI の API と完全に互換性があり、また、OpenAI 互換のエンドポイントを提供するサードパーティ製サービスにも対応しています。
  • Ollama: モデルをローカルでプライベートに実行し、データをクラウドに送信することなく使用できます。
3

動的プロンプトタグ

AI プロンプトをより文脈に沿って強力にするために、ユーザープロンプトとシステムプロンプトの両方で次の動的タグを使用できます。拡張機能は、プロンプトを AI モデルに送信する前に自動的にこれらのタグを置き換えます。

タグ 説明
{DATE} ローカル形式で現在の日に置き換えられます。
{HOUR} ローカル形式で現在の時間に置き換えられます。
{URL} 現在処理中のウェブページの完全な URL です。
{DOMAIN} 処理中のウェブページのルートドメインです。
{LANG} ウェブページの言語です。
{SYSLANG} 現在のシステム/ブラウザの言語設定です。

設定例

以下に、サービスの構成方法のいくつかの例を示します。

例 1: 多言語翻訳アシスタント

サービス名: ローカル言語に翻訳する
リンクされたドメイン: (空 - すべての場所で利用可能)

私はプロの翻訳家です。{LANG} で書かれたサイトを閲覧しており、ブラウザは {SYSLANG} に設定されています。以下のコンテンツを {SYSLANG} に正確に翻訳し、元のマークダウンとテキストの書式を保持してください。

例 2: コードレビューアー (ドメイン固有)

サービス名: Python コードレビュー
リンクされたドメイン: github.com、gitlab.com、stackoverflow.com

あなたは熟練した開発者です。以下に示すコードスニペットは {DOMAIN} で見つかりました。潜在的なバグ、セキュリティ上の脆弱性、およびコーディングの悪い点を厳密に分析してください。コードが何をするのかを説明するのではなく、問題をリストし、修正されたバージョンを提供します。

例 3: 日次ブリーフィングエクストラクター

サービス名: 主要なエンティティを抽出する
リンクされたドメイン: news.ycombinator.com、techcrunch.com、bbc.com

今日は {DATE} の {HOUR} です。以下のニュース記事をスキャンし、言及されている「人物」、「組織」、および「場所」の主要な項目を含む明確な JSON リストを作成してください。

例 4: カスタムアシスタントペルソナ (システムプロンプト)

サービス名: マリオアシスタント
システムプロンプト:

あなたは、賢く機知に富んだアシスタント、マリオです。あなたの仕事は、割り当てられたタスクを可能な限り効率的に実行することです。時間的な参照を含むタスクでは、今日は {DATE} であることを念頭に置いてください。

ユーザープロンプト:

{URL} から取得した以下のテキストを分析し、主要なポイントの要約を提供します。

ブラウザへのインストール

インストールプロセスは、公式のリポジトリから行われるか、開発者モードで未パックのパッケージをロードすることによって行われます。

  • Google Chrome: Chrome Web Store からダウンロード。
  • Mozilla Firefox: Firefox Add-ons からダウンロード。
  • あるいは、開発者モードで未パックの拡張機能をchrome://extensions/またはabout:debuggingを介してロードできます。
info
注: グローバル設定（API キーまたはローカルの Ollama インスタンス）を拡張機能のオプションページで正しく構成してから、キャプチャを実行してください。
