Content Analyzer 拡張機能

無料のAPIキーを取得する

Content Analyzerを効果的に活用するには、AIプロバイダーを設定する必要があります。一部のプロバイダーは利用料金を請求しますが、優れた無料のオプションも用意されています。

以下に、主要なプラットフォーム（Google Gemini、OpenRouter、Groq、Mistral AI、およびOllama）において、無料のAPIキーを取得、またはサービスを設定するための手順を記載します。

1

Google Gemini

Googleは、Google AI Studioを通じて高度なGeminiモデルへのアクセスを提供しています。開発者向けに充実した無料枠が提供されています。なお、無料で利用できるのは、名称に「lite」が含まれるモデル（例：gemini-3.1-flash-lite または gemini-flash-lite-latest など）です。

  • Google AI Studioのウェブサイトにアクセスします。
  • Googleアカウントでサインインします。
  • 左側のナビゲーションメニューから、「Get API key」をクリックします。
  • 「Create API key」ボタンをクリックします。既存のGoogle Cloudプロジェクト内で作成するか、AI Studioに新しいプロジェクトを作成してもらうかを選択できます。
  • 生成されたキーをコピーし、Content AnalyzerのオプションページにあるGeminiプロバイダーの設定に貼り付けます。
2

OpenRouter.ai

OpenRouterは、複数のAIモデルのための統合インターフェースです。さまざまなプロバイダーのモデルを集約しており、いくつかの高品質なモデルを完全に無料で利用できます。

  • OpenRouter.aiのホームページにアクセスします。
  • 既存のアカウント（Google、GitHubなど）を使用してサインアップまたはログインします。
  • ログイン後、メインメニューまたはアカウント設定から「Keys」セクションに移動します。
  • 「Create Key」をクリックします。「Content Analyzer」などの名前を付けます。
  • 新しく生成されたAPIキーをコピーします。Content AnalyzerでOpenRouterのプロバイダーオプションを選択し、APIキーを貼り付け、選択したモデルのID（例：google/gemini-2.5-flash:free）を選択または入力します。
3

Groq

Groqは、オープンソースのAIモデルに対して非常に高速な推論を提供します。現在、開発者向けに高性能な無料枠を提供しています。

  • Groq Consoleにアクセスします。
  • 既存のアカウントを使用してサインアップまたはログインします。
  • サイドバーの「API Keys」セクションに移動します。
  • 「Create API Key」をクリックし、分かりやすい名前を付けます。
  • 生成されたAPIキーをコピーします。Content AnalyzerでGroqのプロバイダーオプションを選択し、APIキーを貼り付け、リストから選択したモデル（例：llama-3.3-70b-versatile）を選択します。
4

Mistral AI

Mistral AIは、La Plateformeを通じて最先端のオープンモデルおよび商用モデルへのアクセスを提供しており、開発者が試行するための無料枠を提供しています。

  • Mistral AI Consoleにアクセスします。
  • アカウントにサインアップまたはログインします。
  • ワークスペースのナビゲーションから「API Keys」セクションに移動します。
  • 「Create new key」をクリックし、生成されたAPIキーをコピーします。
  • Content AnalyzerでMistral AIのプロバイダーオプションを選択し、APIキーを貼り付け、リストから選択したモデル（例：mistral-small-latest、mistral-large-latest、またはcodestral-latest）を選択します。
5

Ollama (ollama.com)

Ollamaは、Webプラットフォームを通じてホストされたモデルに直接接続できるオンラインAPIサービスを提供しています。

  • Ollama.comのウェブサイトにアクセスします。
  • アカウントにログインするか、まだお持ちでない場合はサインアップします。
  • ページ右上のユーザーメニューをクリックします。
  • 「Settings」オプションを選択します。
  • 「Keys」セクションを選択します。
  • 「Add API key」をクリックし、APIキーを生成します。
  • Content AnalyzerでOllamaのAPIタイプを選択し、Base URLをhttps://ollama.com/に設定し、選択したモデルID（例：gemma4:31b）を入力します。
