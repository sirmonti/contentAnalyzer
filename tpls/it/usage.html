Estensione Content Analyzer

Guida all'uso e alla configurazione

Il Content Analyzer è un'estensione del browser progettata per l'estrazione automatizzata e la valutazione dei metadati semantici in ambienti web complessi. Questa estensione funziona su Firefox, Chrome e browser derivati da Chromium; il suo scopo principale è elaborare i contenuti web passandoli attraverso vari servizi di Intelligenza Artificiale (AI).

A differenza dei normali riassumitori di pagine web, questa estensione ti permette di creare più servizi AI personalizzati, ognuno con un prompt altamente specifico che indica esattamente cosa l'intelligenza artificiale debba fare con le informazioni raccolte. Puoi utilizzarla per estrarre codice, tradurre termini specifici, analizzare il sentiment, generare report mirati e molto altro ancora.

Funzionalità principali

  • Cattura contenuti personalizzata: Puoi selezionare facilmente una parte specifica di una pagina web utilizzando uno "strumento hover" interattivo, oppure scegliere di catturare l'intero contenuto della pagina.
  • Prompt AI personalizzati e System Prompt multipli: Crea diversi servizi personalizzati in base alle tue esigenze specifiche con prompt utente personalizzati e System Prompt opzionali (ad esempio, "Riassumi articolo", "Estrai dati JSON", "Traduci in spagnolo", ruoli di assistente personalizzati, ecc.).
  • Servizi per domini specifici: Puoi collegare i tuoi servizi personalizzati a domi web specifici. Questo aiuta a mantenere pulita l'estensione mostrando solo gli strumenti AI pertinenti.
  • Ampia compatibilità con i modelli LLM: Supporta pienamente le connessioni (incluso lo streaming di testo) con server locali tramite Ollama, così come i fornitori di API cloud come Anthropic (Claude), Google Gemini, Groq, OpenRouter, Mistral AI e OpenAI.
2

Fornitori AI supportati

Questa estensione è progettata per essere altamente flessibile, consentendoti di connetterti a una varietà di modelli di Intelligenza Artificiale leader del settore e servizi locali. Attualmente, supporta:

  • Claude (Anthropic): Accedi alla potente famiglia di modelli Claude tramite la loro API ufficiale.
  • Gemini (Google): Connettiti direttamente ai modelli avanzati Gemini di Google.
  • Groq: Inferenza ultra-rapida con modelli dedicati Llama, Mixtral e Gemma.
  • OpenRouter: Accesso unificato a un vasto catalogo di modelli AI da più fornitori.
  • Mistral AI: Connettiti ai modelli Mistral di ultima generazione, sia open che commerciali, tramite la loro API ufficiale.
  • ChatGPT (OpenAI e compatibili): Completamente compatibile con l'API di OpenAI, così come con qualsiasi altro servizio di terze parti che offra un endpoint compatibile con OpenAI.
  • Ollama (o compatibili): Esegui modelli localmente e in modo privato sul tuo dispositivo senza inviare dati in cloud.
3

Tag dinamici per prompt

Per rendere i tuoi prompt AI più contestuali e potenti, puoi utilizzare i seguenti tag dinamici sia nei prompt utente che nei System Prompt. L'estensione li sostituirà automaticamente prima di inviare il prompt al modello di IA:

Tag Descrizione
{DATE} Sostituito dalla data corrente nel tuo formato locale.
{HOUR} Sostituito dall'ora corrente nel tuo formato locale.
{URL} L'URL completo della pagina web attualmente in fase di elaborazione.
{DOMAIN} Il dominio principale della pagina web in fase di elaborazione.
{LANG} La lingua della pagina web.
{SYSLANG} La configurazione della lingua del sistema/browser.
{TITLE} Il titolo HTML della pagina web attualmente in fase di elaborazione.
4

Esempi di configurazione

Di seguito sono riportati alcuni esempi di come puoi strutturare i tuoi servizi:

Esempio 1: Assistente di traduzione multilingue

Nome servizio: Traduci nella lingua locale
Domini collegati: (Vuoto - Disponibile ovunque)

Agisci come un traduttore professionista. Sto navigando in un sito in lingua {LANG} all'indirizzo {URL}, ma il mio browser è impostato su {SYSLANG}. Traduci accuratamente il contenuto seguente in {SYSLANG}, mantenendo intatti il formato markdown e la formattazione del testo.

Esempio 2: Revisione del codice (specifico per dominio)

Nome servizio: Revisione codice Python
Domini collegati: github.com, gitlab.com, stackoverflow.com

Sei uno sviluppatore esperto. I frammenti di codice riportati di seguito sono stati trovati su {DOMAIN}. Analizza il codice esclusivamente per bug potenziali, vulnerabilità di sicurezza e "code smell". Non spiegare cosa faccia il codice, elenchi solo i problemi e fornisci una versione corretta.

Esempio 3: Estrattore di notizie quotidiane

Nome servizio: Estrai entità chiave
Domini collegati: news.ycombinator.com, techcrunch.com, bbc.com

Oggi è {DATE} alle {HOUR}. Analizza il seguente articolo di notizie ed estrai una lista JSON pulita contenente le principali "Persone", "Organizzazioni" e "Luoghi" menzionati nel testo.

Esempio 4: Persona assistente personalizzata (System Prompt)

Nome servizio: Assistente Mario
System Prompt:

Sei Mario, un assistente intelligente e perspicace; il tuo compito è svolgere le attività assegnate il più efficientemente possibile. Per le attività con riferimenti temporali, devi tenere a mente che oggi è {DATE}

Prompt utente:

Analizza il testo seguente catturato da {URL} e fornisci un riassunto dei punti principali.
5

Installazione nel browser

Il processo di installazione avviene tramite il repository ufficiale oppure caricando il pacchetto non impacchettato in modalità sviluppatore.

  • Google Chrome: Scarica da Chrome Web Store.
  • Mozilla Firefox: Scarica da Firefox Add-ons.
  • In alternativa, puoi caricare l'estensione non impacchettata in modalità sviluppatore tramite chrome://extensions/ o about:debugging.
info
Nota: Assicurati di aver configurato correttamente le impostazioni globali (Chiavi API o istanze locali Ollama) nella pagina Opzioni dell'estensione prima di eseguire qualsiasi cattura.
