תוספת Content Analyzer

קבלו מפתח API חינמי

כדי להשתמש ב-Content Analyzer בצורה יעילה, תצטרכו להגדיר ספק AI. בעוד שחלק מהספקים גובים תשלום על השימוש שלהם, קיימות אפשרויות חינמיות מצוינות.

למטה תמצאו הנחיות כיצד להשיג מפתחות API בחינם או להגדיר שירותים בפלטפורמות פופולריות: Google Gemini, OpenRouter, Groq, Mistral AI, ו-Ollama.

1

Google Gemini

גוגל מציעה גישה למודלי ה-Gemini המתקדמים שלה דרך Google AI Studio. הם מספכים שכבת חינם נדיבה למפתחים. שימו לב שהמודלים שניתן להשתמש בהם בחינם הם אלו המכילים את המילה "lite" בשמם, כגון gemini-3.1-flash-lite או gemini-flash-lite-latest.

  • גלושו לאתר Google AI Studio.
  • התחברו עם חשבון הגוגל שלכם.
  • בתפריט הניווט בצד שמאל, לחצו על "Get API key".
  • לחצו על כפתור "Create API key". תוכלו לבחור ליצור אותו בתוך פרויקט Google Cloud קיים או לאפשר ל-AI Studio ליצור אחד חדש עבורכם.
  • העתיקו את המפתח שנוצר והדביקו אותו בדף ה-Options של Content Analyzer תחת הגדרות הספק Gemini.
2

OpenRouter.ai

OpenRouter הוא ממשק מאחד עבור מודלי AI מרובים. הוא מרכז מודלים של ספקים שונים, ומספר מודלי איכות גבוהים זמינים בחינם לחלוטין.

  • עברו לדף הבית של OpenRouter.ai.
  • הירשמו או התחברו באמצעות חשבון קיים (Google, GitHub וכו').
  • לאחר ההתחברות, עברו לסעיף "Keys" מהתפריט הראשי או מהגדרות החשבון שלכם.
  • לחצו על "Create Key". תנו לו שם כמו "Content Analyzer".
  • העתיקו את מפתח ה-API החדש שלכם. ב-Content Analyzer, בחרו באפשרות הספק OpenRouter, הדביקו את מפתח ה-API שלכם, ובחרו או הזינו את ה-ID של המודל שבחרתם (לדוגמה, google/gemini-2.5-flash:free).
3

Groq

Groq מספקת הסקה מהירה מאוד עבור מודלי AI בקוד פתוח. כרור היא מציעה שכבת חינם עם ביצועים גבוהים למפתחים.

  • גלושו ל-Groq Console.
  • הירשמו או התחברו באמצעות חשבון קיים.
  • עברו לסעיף "API Keys" בסרגל הצד.
  • לחצו על "Create API Key" ותנו לו שם תיאורי.
  • העתיקו את מפתח ה-API שנוצר. ב-Content Analyzer, בחרו באפשרות הספק Groq, הדביקו את מפתח ה-API שלכם, ובחרו מודל מתוך הרשימה (לדוגמה, llama-3.3-70b-versatile).
4

Mistral AI

Mistral AI מספקת גישה למודלים מסחריים ופתוחים מתקדמים דרך La Plateforme, ומציעה שכבות חינמיות למפתחים שרוצים להתנסות.

  • גלושו ל-Mistral AI Console.
  • הירשמו או התחברו לחשבון שלכם.
  • עברו לסעיף "API Keys" מתוך ניווט שטח העבודה.
  • לחצו על "Create new key" והעתיקו את מפתח ה-API שנוצר.
  • ב-Content Analyzer, בחרו באפשרות הספק Mistral AI, הדביקו את מפתח ה-API שלכם, ובחרו מודל מתוך הרשימה (לדוגמה, mistral-small-latest, mistral-large-latest, או codestral-latest).
5

Ollama (ollama.com)

Ollama מספקת שירות API מקוון המאפשר לכם להתחבר ישירות למודלי מאוחסנים דרך פלטפורמת האינטרנט שלהם.

  • גלושו לאתר Ollama.com.
  • התחברו לחשבון שלכם או הירשמו אם אין לכם עדיין אחד.
  • לחצו על תפריט המשתמש שלכם הממוקם בפינה העליונה של הדף.
  • בחרו באפשרות "Settings".
  • בחרו בסעיף "Keys".
  • לחצו על "Add API key" וצרו מפתח API.
  • ב-Content Analyzer, בחרו בסוג ה-API Ollama, קבעו את ה-Base URL ל-https://ollama.com/, והזינו את ה-ID של המודל שבחרתם (לדוגמה, gemma4:31b).
