콘텐츠 분석기 확장 프로그램

사용 및 구성 가이드

콘텐츠 분석기는 복잡한 웹 환경에서 의미 있는 메타데이터를 자동 추출 및 평가하도록 설계된 브라우저 확장 프로그램입니다. 이 확장 프로그램은 Firefox, Chrome 및 Chromium 기반 브라우저에서 작동하며, 핵심 목적은 다양한 인공 지능(AI) 서비스를 통해 웹 콘텐츠를 처리하는 것입니다.

일반적인 웹 페이지 요약 도구와 달리, 이 확장 프로그램을 사용하면 수집된 정보에 대해 AI가 수행해야 할 작업을 정확하게 지정하는 매우 구체적인 프롬프트를 사용하여 여러 개의 사용자 정의 AI 서비스를 만들 수 있습니다. 이를 통해 코드를 추출하고, 특정 용어를 번역하고, 감성을 분석하고, 타겟 보고서를 생성하는 등 다양한 작업을 수행할 수 있습니다.

주요 기능

  • 사용자 정의 콘텐츠 캡처: 대화형 "마우스 오버 도구"를 사용하여 웹 페이지의 특정 부분을 쉽게 선택하거나 전체 페이지 콘텐츠를 캡처하도록 설정할 수 있습니다.
  • 다중 사용자 지정 AI 프롬프트 및 시스템 프롬프트: 사용자 정의 프롬프트와 선택 사항인 시스템 프롬프트를 통해 정확히 필요한 대로 서비스를 구성하여 다양한 서비스를 만들 수 있습니다(예: "기사 요약", "JSON 데이터 추출", "스페인어로 번역", 사용자 정의 어시스턴트 페르소나 등).
  • 도메인별 서비스: 사용자 정의 서비스를 특정 웹 도메인에 연결할 수 있습니다. 이렇게 하면 관련 AI 도구만 표시되므로 확장 프로그램이 깔끔하게 유지됩니다.
  • 광범위한 LLM 호환성: Ollama를 통해 로컬 서버와 연결하고, OpenAI, Anthropic 및 Google Gemini와 같은 클라우드 API 제공업체와의 연결을 포함하여 (텍스트 스트리밍 포함) 완벽하게 지원합니다.
2

지원되는 AI 제공업체

이 확장 프로그램은 다양한 업계 최고의 인공 지능 모델 및 로컬 서비스에 연결할 수 있도록 매우 유연하게 설계되었습니다. 현재 다음과 같은 서비스를 지원합니다.

  • Claude (Anthropic): 공식 API를 통해 강력한 Claude 제품군에 액세스할 수 있습니다.
  • Gemini (Google): Google의 고급 Gemini 모델에 직접 연결할 수 있습니다.
  • ChatGPT (OpenAI 및 호환): OpenAI의 API와 완벽하게 호환되며, OpenAI 호환 엔드포인트를 제공하는 다른 타사 서비스에서도 사용할 수 있습니다.
  • Ollama: 데이터를 클라우드로 보내지 않고도 로컬에서 개인적으로 모델을 실행할 수 있습니다.
3

동적 프롬프트 태그

AI 프롬프트를 더욱 상황에 맞게 강력하게 만들기 위해 사용자 프롬프트와 시스템 프롬프트 모두에서 다음 동적 태그를 사용할 수 있습니다. 확장 프로그램은 AI 모델로 프롬프트를 보내기 전에 자동으로 해당 태그를 대체합니다.

태그 설명
{DATE} 현재 로컬 형식의 날짜로 대체됩니다.
{HOUR} 현재 로컬 형식의 시간으로 대체됩니다.
{URL} 현재 처리 중인 웹 페이지의 전체 URL입니다.
{DOMAIN} 처리 중인 웹 페이지의 루트 도메인입니다.
{LANG} 웹 페이지의 언어입니다.
{SYSLANG} 현재 시스템/브라우저 언어 구성입니다.
4

예제 구성

아래는 서비스 구성을 보여주는 몇 가지 예입니다.

예제 1: 다국어 번역 어시스턴트

서비스 이름: 로컬 언어로 번역
연결된 도메인: (비어 있음 - 모든 곳에서 사용 가능)

저는 전문 번역가입니다. 현재 {LANG} 언어로 된 사이트를 방문하고 있지만 브라우저 설정은 {SYSLANG}입니다. 다음 콘텐츠를 {SYSLANG}으로 정확하게 번역하되, 원래 마크다운 및 텍스트 형식을 유지하십시오.

예제 2: 코드 검토자 (도메인별)

서비스 이름: Python 코드 검토
연결된 도메인: github.com, gitlab.com, stackoverflow.com

저는 전문가 개발자입니다. 아래 코드는 {DOMAIN}에서 발견되었습니다. 잠재적인 버그, 보안 취약점 및 코드 문제에 대해 엄격하게 분석하십시오. 코드가 무엇을 하는지 설명하지 말고, 문제를 나열하고 수정된 버전을 제공하십시오.

예제 3: 일일 브리핑 추출기

서비스 이름: 주요 엔터티 추출
연결된 도메인: news.ycombinator.com, techcrunch.com, bbc.com

오늘은 {DATE}이고 시간은 {HOUR}입니다. 다음 뉴스 기사를 스캔하고 언급된 주요 "인물", "조직" 및 "위치"를 포함하는 깔끔한 JSON 목록을 추출하십시오.

예제 4: 사용자 정의 어시스턴트 페르소나 (시스템 프롬프트)

서비스 이름: 마리오 어시스턴트
시스템 프롬프트:

당신은 똑똑하고 능숙한 어시스턴트인 마리오입니다. 당신의 임무는 주어진 작업을 최대한 효율적으로 수행하는 것입니다. 시간 참조가 있는 작업에서는 오늘이 {DATE}라는 점을 염두에 두어야 합니다.

사용자 프롬프트:

{URL}에서 캡처한 다음 텍스트를 분석하고 주요 내용을 요약하십시오.

브라우저 설치

설치 프로세스는 공식 리포지토리를 통해 또는 개발자 모드에서 압축 해제된 패키지를 로드하여 수행됩니다.

  • Google Chrome: Chrome 웹 스토어에서 다운로드
  • Mozilla Firefox: Firefox 추가 기능에서 다운로드
  • 또는, chrome://extensions/ 또는 about:debugging을 통해 개발자 모드에서 압축 해제된 확장을 로드할 수 있습니다.
info
