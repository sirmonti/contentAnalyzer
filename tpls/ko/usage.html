콘텐츠 분석기 확장 프로그램

사용 및 구성 가이드

콘텐츠 분석기는 복잡한 웹 환경에서 의미론적 메타데이터를 자동으로 추출하고 평가하도록 설계된 브라우저 확장 프로그램입니다. 이 확장 프로그램은 Firefox, Chrome 및 Chromium 기반 브라우저에서 작동하며, 핵심 목적은 다양한 인공 지능(AI) 서비스를 통해 웹 콘텐츠를 처리하는 것입니다.

일반적인 웹 페이지 요약 도구와 달리, 이 확장 프로그램을 사용하면 AI가 수집된 정보로 무엇을 해야 하는지 정확히 지정하는 매우 구체적인 프롬프트를 가진 여러 개의 사용자 지정 AI 서비스를 만들 수 있습니다. 이를 사용하여 코드 추출, 특정 용어 번역, 감성 분석, 대상 보고서 생성 등을 수행할 수 있습니다.

1

주요 기능

  • 맞춤형 콘텐츠 캡처: 대화형 "마우스 오버 도구"를 사용하여 웹 페이지의 특정 부분을 쉽게 선택하거나 전체 페이지 콘텐츠를 캡처하도록 선택할 수 있습니다.
  • 다중 사용자 지정 AI 프롬프트 및 시스템 프롬프트: 사용자 지정 프롬프트와 선택적 시스템 프롬프트(예: "기사 요약", "JSON 데이터 추출", "스페인어로 번역", 사용자 지정 어시스턴트 페르소나 등)를 사용하여 정확한 요구 사항에 맞는 다양한 서비스를 만듭니다.
  • 도메인별 서비스: 사용자 지정 서비스를 특정 웹 도메인과 연결할 수 있습니다. 이렇게 하면 관련 AI 도구만 표시하여 확장 프로그램을 깔끔하게 유지하는 데 도움이 됩니다.
  • 광범위한 LLM 호환성: Ollama를 통해 로컬 서버와의 연결(텍스트 스트리밍 포함)과 OpenAI, Anthropic 및 Google Gemini와 같은 클라우드 API 제공업체와의 연결을 완벽하게 지원합니다.
2

지원되는 AI 제공업체

이 확장 프로그램은 다양한 업계 최고의 인공 지능 모델 및 로컬 서비스에 연결할 수 있도록 매우 유연하게 구축되었습니다. 현재 지원하는 서비스는 다음과 같습니다.

  • Claude(Anthropic): 공식 API를 통해 강력한 Claude 제품군에 액세스합니다.
  • Gemini(Google): Google의 고급 Gemini 모델에 직접 연결합니다.
  • ChatGPT(OpenAI 및 호환): OpenAI의 API 및 OpenAI 호환 엔드포인트를 제공하는 다른 타사 서비스와 완벽하게 호환됩니다.
  • Ollama: 데이터를 클라우드로 보내지 않고 로컬에서 개인적으로 모델을 실행합니다.
3

동적 프롬프트 태그

AI 프롬프트를 더욱 상황에 맞게 효과적으로 만들려면 사용자 프롬프트와 시스템 프롬프트 모두에서 다음 동적 태그를 사용할 수 있습니다. 확장 프로그램은 AI 모델에 프롬프트를 보내기 전에 자동으로 해당 태그를 대체합니다.

태그 설명
{DATE} 현재 로컬 형식의 날짜로 대체됩니다.
{HOUR} 현재 로컬 형식의 시간으로 대체됩니다.
{URL} 현재 처리 중인 웹 페이지의 전체 URL입니다.
{DOMAIN} 처리 중인 웹 페이지의 루트 도메인입니다.
{LANG} 웹 페이지의 언어입니다.
{SYSLANG} 현재 시스템/브라우저 언어 구성입니다.
{TITLE} 현재 처리 중인 웹 페이지의 HTML 제목입니다.
4

예제 구성

다음은 서비스를 구성하는 방법을 보여주는 몇 가지 예입니다.

예제 1: 다국어 번역 어시스턴트

서비스 이름: 현지 언어로 번역
연결된 도메인: (비어 있음 - 어디에서나 사용 가능)

저는 전문 번역가입니다. 웹 사이트를 {LANG} 언어로 보고 있는데, 브라우저 언어는 {SYSLANG}입니다. 다음 콘텐츠를 {SYSLANG}으로 정확하게 번역하고, 원래 마크다운 및 텍스트 형식을 유지하십시오.

예제 2: 코드 검토자(도메인별)

서비스 이름: Python 코드 검토
연결된 도메인: github.com, gitlab.com, stackoverflow.com

당신은 숙련된 개발자입니다. 아래 코드 스니펫은 {DOMAIN}에서 찾았습니다. 잠재적인 버그, 보안 취약점 및 코드 문제에 대해 엄격하게 분석하십시오. 코드가 수행하는 작업을 설명하지 말고, 문제를 나열하고 수정된 버전을 제공하십시오.

예제 3: 일일 브리핑 추출기

서비스 이름: 핵심 엔터티 추출
연결된 도메인: news.ycombinator.com, techcrunch.com, bbc.com

오늘은 {DATE}이고 시간은 {HOUR}입니다. 다음 뉴스 기사를 스캔하고 "사람", "조직" 및 "위치"의 주요 항목을 포함하는 깔끔한 JSON 목록을 추출하십시오.

예제 4: 사용자 지정 어시스턴트 페르소나(시스템 프롬프트)

서비스 이름: 마리오 어시스턴트
시스템 프롬프트:

당신은 똑똑하고 재치 있는 어시스턴트인 마리오입니다. 당신의 임무는 할당된 작업을 가능한 한 효율적으로 수행하는 것입니다. 시간에 대한 참조가 있는 작업에서는 오늘이 {DATE}라는 점을 염두에 두어야 합니다.

사용자 프롬프트:

{URL}에서 캡처한 다음 텍스트를 분석하고 주요 내용을 요약하십시오.
5

브라우저 설치

설치 프로세스는 공식 리포지토리를 통해 또는 개발자 모드에서 압축 해제된 패키지를 로드하여 수행됩니다.

  • Google Chrome: Chrome 웹 스토어에서 다운로드합니다.
  • Mozilla Firefox: Firefox 부가 기능에서 다운로드합니다.
  • 또는 개발자 모드에서 chrome://extensions/ 또는 about:debugging을 통해 압축 해제된 확장 프로그램을 로드할 수 있습니다.
info
참고: 확장 프로그램의 옵션 페이지에서 전역 설정을 올바르게 구성(API 키 또는 로컬 Ollama 인스턴스)한 후 캡처를 실행하십시오.
