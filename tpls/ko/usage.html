콘텐츠 분석기 확장 프로그램

사용 및 설정 가이드

콘텐츠 분석기는 복잡한 웹 환경에서 의미론적 메타데이터를 자동으로 추출하고 평가하기 위해 설계된 브라우저 확장 프로그램입니다. 이 확장 프로그램은 Firefox, Chrome 및 Chromium 기반 브라우저에서 작동하며, 주요 목적은 웹 콘텐츠를 다양한 인공지능(AI) 서비스를 통해 처리하는 것입니다.

일반적인 웹 페이지 요약 도구와 달리, 이 확장 프로그램은 각각의 역할이 정의된 고도로 구체적인 프롬프트를 기반으로 여러 개의 맞춤형 AI 서비스를 생성할 수 있게 해줍니다. 이를 사용하여 코드를 추출하거나, 특정 용어를 번역하고, 감성 분석을 수행하거나, 타겟팅된 보고서를 생성하는 등 다양한 작업을 수행할 수 있습니다.

1

주요 기능

  • 맞춤형 콘텐츠 캡처: 상호작용형 "호버 도구"를 사용하여 웹 페이지의 특정 부분을 쉽게 선택하거나, 페이지 전체 내용을 캡처하도록 선택할 수 있습니다.
  • 다수의 맞춤형 AI 프롬프트 및 시스템 프롬프트: 사용자 맞춤형 프롬프트와 선택적 시스템 프롬프트(예: "기사 요약", "JSON 데이터 추출", "스페인어로 번역", 맞춤형 비서 페르소나 등)를 통해 사용자의 필요에 딱 맞는 다양한 서비스를 생성할 수 있습니다.
  • 도메인 특화 서비스: 맞춤형 서비스를 특정 웹 도메인에 연결할 수 있습니다. 이를 통해 관련성 있는 AI 도구만 표시하여 확장 프로그램을 깔끔하게 관리할 수 있습니다.
  • 광범위한 LLM 호환성: Ollama를 통한 로컬 서버 연결(텍스트 스트리밍 포함)뿐만 아니라 Anthropic(Claude), Google Gemini, Groq, OpenRouter, Mistral AI, 그리고 OpenAI와 같은 클라우드 API 제공업체를 모두 지원합니다.
2

지원되는 AI 제공업체

이 확장 프로그램은 높은 유연성을 갖도록 구축되어, 다양한 업계 선도적인 인공지능 모델 및 로컬 서비스에 연결할 수 있습니다. 현재 지원되는 항목은 다음과 같습니다:

  • Claude (Anthropic): 공식 API를 통해 강력한 Claude 모델군에 액세스할 수 있습니다.
  • Gemini (Google): Google의 고급 Gemini 모델에 직접 연결됩니다.
  • Groq: 전용 Llama, Mixtral, Gemma 모델을 통한 초고속 추론을 지원합니다.
  • OpenRouter: 여러 제공업체의 방대한 AI 모델 카탈로그에 통합적으로 액세스할 수 있습니다.
  • Mistral AI: 공식 API를 통해 최첨단 오픈 및 상용 Mistral 모델에 연결됩니다.
  • ChatGPT (OpenAI 및 호환 서비스): OpenAI의 API뿐만 아니라, OpenAI 호환 엔드포인트를 제공하는 모든 제3자 서비스와 완벽하게 호환됩니다.
  • Ollama (또는 호환 서비스): 데이터를 클라우드로 전송하지 않고 사용자 기기에서 로컬로 프라이빗하게 모델을 실행할 수 있습니다.
3

프롬프트 동적 태그

AI 프롬프트를 더욱 문맥에 맞고 강력하게 만들기 위해, 사용자 프롬프트와 시스템 프롬프트 모두에서 다음 동적 태그를 활용할 수 있습니다. 확장 프로그램은 AI 모델에 프롬프트를 전송하기 전에 이 태그를 자동으로 치환합니다:

태그 설명
{DATE} 사용자의 지역 형식에 따른 현재 날짜로 대체됩니다.
{HOUR} 사용자의 지역 형식에 따른 현재 시간으로 대체됩니다.
{URL} 현재 처리 중인 웹 페이지의 전체 URL입니다.
{DOMAIN} 처리 중인 웹 페이지의 루트 도메인입니다.
{LANG} 웹 페이지의 언어입니다.
{SYSLANG} 현재 시스템/브라우저 언어 설정입니다.
{TITLE} 현재 처리 중인 웹 페이지의 HTML 제목입니다.
4

설정 예시

다음은 서비스를 구축하는 방법을 보여주는 몇 가지 예시입니다:

예시 1: 다국어 번역 비서

서비스 이름: 로컬 언어로 번역
연결된 도메인: (비어 있음 - 모든 곳에서 사용 가능)

전문 번역가로 활동하십시오. 저는 {URL}에 있는 {LANG} 언어 사이트를 탐색 중이지만, 제 브라우저는 {SYSLANG}로 설정되어 있습니다. 원본 마크다운과 텍스트 형식을 유지하면서 다음 내용을 {SYSLANG}로 정확하게 번역해 주세요.

예시 2: 코드 검토기 (도메인 특화)

서비스 이름: 파이썬 코드 검토
연결된 도메인: github.com, gitlab.com, stackoverflow.com

당신은 전문 개발자입니다. 아래 제공된 코드 스니펫은 {DOMAIN}에서 발견되었습니다. 잠재적인 버그, 보안 취약점 및 코드 스멜(code smell)을 엄격하게 분석하십시오. 코드가 무엇을 하는지 설명하지 말고, 문제점 목록과 수정된 버전을 제공하십시오.

예시 3: 일일 브리핑 추출기

서비스 이름: 주요 개체 추출
연결된 도메인: news.ycombinator.com, techcrunch.com, bbc.com

오늘은 {DATE} {HOUR}입니다. 다음 뉴스 기사를 스캔하고 본문에서 언급된 주요 '인물', '조직', '장소'를 포함하는 깔끔한 JSON 리스트를 추출하십시오.

예시 4: 맞춤형 비서 페르소나 (시스템 프롬프트)

서비스 이름: 마리오 비서
시스템 프롬프트:

당신은 똑똑하고 날카로운 비서인 마리이며, 당신의 임무는 할당된 업무를 가능한 한 효율적으로 완수하는 것입니다. 시간적 언급이 포함된 업무의 경우, 오늘이 {DATE}임을 반드시 유념하십시오.

사용자 프롬프트:

{URL}에서 캡처한 다음 텍스트를 분석하고 주요 사항을 요약해 주십시오.
5

브라우저 설치

설치 과정은 공식 저장소를 통하거나 개발자 모드에서 압축을 해제한 패키지를 로드하여 진행됩니다.

  • Google Chrome: Chrome 웹 스토어에서 다운로드.
  • Mozilla Firefox: Firefox 부가 기능에서 다운로드.
  • 대신, chrome://extensions/ 또는 about:debugging을 통해 개발자 모드에서 압축을 해제한 확장 프로그램을 로드할 수 있습니다.
