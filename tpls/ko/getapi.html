콘텐츠 분석기 확장 프로그램

무료 API 키를 받으세요

콘텐츠 분석기를 효과적으로 사용하려면 AI 공급자를 구성해야 합니다. 일부 공급자는 사용량에 따라 요금을 부과하지만, 훌륭한 무료 옵션도 있습니다.

아래에는 Google Gemini, OpenRouter, Groq, Mistral AI 및 Ollama와 같은 인기 있는 플랫폼에서 무료 API 키를 얻거나 서비스를 설정하는 방법에 대한 지침이 나와 있습니다.

1

Google Gemini

Google은 Google AI Studio를 통해 고급 Gemini 모델에 대한 액세스를 제공합니다. 개발자를 위한 충분한 무료 요금제를 제공합니다. 무료로 사용할 수 있는 모델은 이름에 "lite"라는 단어가 포함된 모델(예: gemini-3.1-flash-lite 또는 gemini-flash-lite-latest)입니다.

  • Google AI Studio 웹사이트를 방문하세요.
  • Google 계정으로 로그인합니다.
  • 왼쪽 탐색 메뉴에서 "API 키 받기"를 클릭합니다.
  • "API 키 만들기" 버튼을 클릭합니다. 기존 Google Cloud 프로젝트에서 만들거나 AI Studio에서 새 프로젝트를 만들도록 선택할 수 있습니다.
  • 생성된 키를 복사하여 Gemini 공급자 설정의 콘텐츠 분석기 옵션 페이지에 붙여넣습니다.
2

OpenRouter.ai

OpenRouter는 여러 AI 모델을 위한 통합 인터페이스입니다. 다양한 공급자의 모델을 모아 제공하며, 그중 일부 고품질 모델은 완전히 무료로 사용할 수 있습니다.

  • OpenRouter.ai 홈페이지로 이동합니다.
  • 기존 계정(Google, GitHub 등)을 사용하여 가입하거나 로그인합니다.
  • 로그인 후 주 메뉴 또는 계정 설정에서 "키" 섹션으로 이동합니다.
  • "키 만들기"를 클릭합니다. "콘텐츠 분석기"와 같은 이름을 지정합니다.
  • 새 API 키를 복사합니다. 콘텐츠 분석기에서 OpenAI 호환 옵션을 선택하고, 기본 URL을 https://openrouter.ai/api/v1으로 설정하고, 선택한 모델의 ID(예: google/gemini-2.5-flash:free)를 입력하여 사용할 수 있습니다.
3

Groq

Groq은 오픈 소스 AI 모델에 대한 매우 빠른 추론을 제공합니다. 현재 개발자를 위한 높은 성능의 무료 요금제를 제공합니다.

  • Groq 콘솔을 방문합니다.
  • 가입하거나 기존 계정으로 로그인합니다.
  • 사이드바에서 "API 키" 섹션으로 이동합니다.
  • "API 키 만들기"를 클릭하고 설명이 포함된 이름을 지정합니다.
  • 생성된 API 키를 복사합니다. 콘텐츠 분석기에서 OpenAI 호환 옵션을 사용하고, 기본 URL을 https://api.groq.com/openai/v1으로 설정하고, 선택한 모델의 ID(예: llama3-8b-8192)를 입력합니다.
4

Mistral AI

Mistral AI는 La Plateforme를 통해 최첨단 오픈 및 상용 모델에 대한 액세스를 제공하며, 개발자가 실험할 수 있도록 무료 요금제를 제공합니다.

  • Mistral AI 콘솔을 방문합니다.
  • 계정에 가입하거나 로그인합니다.
  • 작업 공간 탐색에서 "API 키" 섹션으로 이동합니다.
  • "새 키 만들기"를 클릭하고 생성된 API 키를 복사합니다.
  • 콘텐츠 분석기에서 OpenAI 호환 옵션을 선택하고, 기본 URL을 https://api.mistral.ai/v1로 설정하고, 선택한 모델 ID(예: mistral-small-latest)를 입력합니다.
5

Ollama (ollama.com)

Ollama는 온라인 API 서비스를 제공하여 웹 플랫폼을 통해 호스팅된 모델에 직접 연결할 수 있습니다.

  • Ollama.com 웹사이트를 방문합니다.
  • 계정에 로그인하거나 아직 계정이 없다면 가입합니다.
  • 페이지의 오른쪽 상단에 있는 사용자 메뉴를 클릭합니다.
  • "설정" 옵션을 선택합니다.
  • "키" 섹션을 선택합니다.
  • "API 키 추가"를 클릭하여 API 키를 생성합니다.
  • 콘텐츠 분석기에서 Ollama API 유형을 선택하고 기본 URL을 https://ollama.com/으로 설정하고, 선택한 모델 ID(예: gemma4:31b)를 입력합니다.
