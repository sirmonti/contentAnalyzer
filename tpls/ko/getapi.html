Content Analyzer 확장 프로그램

무료 API 키 받기

Content Analyzer를 효과적으로 사용하려면 AI 제공업체를 설정해야 합니다. 일부 제공업체는 사용료를 부과하지만, 훌륭한 무료 옵션도 많이 있습니다.

아래에서 Google Gemini, OpenRouter, Groq, Mistral AI 및 Ollama와 같은 인기 플랫폼에서 무료 API 키를 받거나 서비스를 설정하는 방법을 확인하실 수 있습니다.

1

Google Gemini

Google은 Google AI Studio를 통해 고급 Gemini 모델에 대한 접근을 제공합니다. 개발자를 위해 관대한 무료 등급을 제공합니다. 무료로 사용할 수 있는 모델은 이름에 "lite"라는 단어가 포함된 모델(예: gemini-3.1-flash-lite 또는 gemini-flash-lite-latest)임을 유의하십시오.

  • Google AI Studio 웹사이트를 방문하십시오.
  • Google 계정으로 로그인하십시오.
  • 왼쪽 탐색 메뉴에서 "Get API key"를 클릭하십시오.
  • "Create API key" 버튼을 클릭하십시오. 기존 Google Cloud 프로젝트에서 생성하거나 AI Studio가 대신 새 프로젝트를 생성하도록 선택할 수 있습니다.
  • 생성된 키를 복사하여 Content Analyzer의 옵션 페이지 내 Gemini 제공업체 설정에 붙여넣으십시오.
2

OpenRouter.ai

OpenRouter는 여러 AI 모델을 위한 통합 인터페이스입니다. 다양한 제공업체의 모델을 통합하며, 여러 고품질 모델을 완전히 무료로 이용할 수 있습니다.

  • OpenRouter.ai 홈페이지로 이동하십시오.
  • 기존 계정(Google, GitHub 등)을 사용하여 가입하거나 로그인하십시오.
  • 로그인 후, 기본 메뉴 또는 계정 설정에서 "Keys" 섹션으로 이동하십시오.
  • "Create Key"를 클릭하십시오. "Content Analyzer"와 같은 이름을 부여하십시오.
  • 새 API 키를 복사하십시오. Content Analyzer에서 OpenRouter 제공업체 옵션을 선택하고, API 키를 붙여넣은 후, 선택한 모델의 ID(예: google/gemini-2.5-flash:free)를 선택하거나 입력하십시오.
3

Groq

Groq는 오픈 소스 AI 모델에 대해 매우 빠른 추론을 제공합니다. 현재 개발자를 위해 고성능의 무료 등급을 제공하고 있습니다.

  • Groq Console을 방문하십시오.
  • 기존 계정을 사용하여 가입하거나 로그인하십시오.
  • 사이드바에서 "API Keys" 섹션으로 이동하십시오.
  • "Create API Key"를 클릭하고 적절한 이름을 입력하십시오.
  • 생성된 API 키를 복사하십시오. Content Analyzer에서 Groq 제공업체 옵션을 선택하고 API 키를 붙여넣은 후, 목록에서 선택한 모델(예: llama-3.3-70b-versatile)을 선택하십시오.
4

Mistral AI

Mistral AI는 La Plateforme을 통해 최첨단 오픈 및 상용 모델에 대한 접근을 제공하며, 개발자가 실험할 수 있는 무료 등급을 제공합니다.

  • Mistral AI Console을 방문하십시오.
  • 계정에 가입하거나 로그인하십시오.
  • 워크스페이스 내비게이션에서 "API Keys" 섹션으로 이동하십시오.
  • "Create new key"를 클릭하고 생성된 API 키를 복사하십시오.
  • Content Analyzer에서 Mistral AI 제공업체 옵션을 선택하고, API 키를 붙여넣은 후, 목록에서 선택한 모델(예: mistral-small-latest, mistral-large-latest, 또는 codestral-latest)을 선택하십시오.
5

Ollama (ollama.com)

Ollama는 웹 플랫폼을 통해 호스팅된 모델에 직접 연결할 수 있는 온라인 API 서비스를 제공합니다.

  • Ollama.com 웹사이트를 방문하십시오.
  • 계정에 로그인하거나 아직 계정이 없는 경우 가입하십시오.
  • 페이지 오른쪽 상단에 있는 사용자 메뉴를 클릭하십시오.
  • "Settings" 옵션을 선택하십시오.
  • "Keys" 섹션을 선택하십시오.
  • "Add API key"를 클릭하고 API 키를 생성하십시오.
  • Content Analyzer에서 Ollama API 유형을 선택하고 Base URL을 https://ollama.com/로 설정한 후, 선택한 모델 ID(예: gemma4:31b)를 입력하십시오.
