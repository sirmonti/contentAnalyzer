개인정보 처리방침

최종 업데이트: 2026년 4월

1. 서론

"contentAnalyzer" 크롬 확장 프로그램(이하 "확장 프로그램")은 사용자가 설정한 인공지능 서비스를 사용하여 현재 웹페이지의 콘텐츠를 처리하도록 설계되었습니다. 본 개인정보 처리방침은 귀하의 개인정보 보호에 대한 당사의 약속과 데이터가 어떻게 처리되는지를 설명합니다.

2. 개발자에 의한 데이터 수집 없음

당사는 귀하의 개인정보를 무엇보다 소중하게 여깁니다. 이 확장 프로그램의 개발자는 사용자의 개인 데이터, 브라우징 기록 또는 처리된 콘텐츠를 개발자가 제어하는 어떤 서버로도 수집, 저장 또는 전송하지 않습니다.

모든 구성 설정(API 키 또는 사용자 정의 프롬프트 등)은 브라우저 내의 로컬 저장소(예: chrome.storage.local)에 저장되며, 개발자가 이를 접근할 수 없습니다.

3. 제3자 서비스로의 데이터 전송

확장 프로그램이 핵심 기능을 제공하기 위해, 사용자가 분석을 선택한 웹페이지의 콘텐츠를 설정에서 구성한 제3자 AI 서비스 제공업체(이하 "AI 서비스")로 전송합니다.

3.1. 사용자 설정 서비스

확장 프로그램은 사용자가 제공한 특정 엔드포인트/API와만 통신합니다. 이러한 서비스는 사용자에 의해 선택되고 구성되므로, "contentAnalyzer" 개발자는 이러한 제3자 사이트가 전송받은 데이터를 처리하는 방식에 대해 어떠한 권한도 가지고 있지 않습니다.

3.2. 제3자 개인정보 처리방침

개발자는 사용자가 선택하여 사용하는 AI 서비스의 개인정보 보호 관행, 데이터 보유 정책 또는 보안 조치에 대해 책임을 지지 않습니다. 특정 서비스를 사용하여 확장 프로그램을 이용하기 전에 해당 제공업체의 개인정보 처리방침과 서비스 약관을 검토할 것을 강력히 권장합니다.

4. 권한

확장 프로그램이 기능하기 위해서는 다음과 같은 특정 권한이 필요합니다:

  • activeTab 또는 <all_urls>: 분석하고자 하는 페이지의 콘텐츠를 읽기 위해 필요합니다.
  • storage: 구성 및 API 설정을 로컬에 저장하기 위해 필요합니다.
  • 호스트 권한: 사용자가 지정한 AI 서비스 API로 콘텐츠를 보내기 위해 필요합니다.

5. 보안

확장 프로그램은 표준 웹 프로토콜을 통해 데이터 전송을 지원하지만, 브라우저를 벗어난 후의 데이터 보안은 사용자가 설정한 AI 서비스에 전적으로 달려 있습니다. 당사는 보안(HTTPS) API 엔드포인트를 제공하는 서비스를 사용할 것을 권장합니다.

6. 정책 변경 사항

개발자는 언제든지 본 개인정보 처리방침을 업데이트할 권리를 보유합니다. 모든 변경 사항은 확장 프로그램의 새로운 버전에 반영되며, 이 페이지에 업데이트될 것입니다.

7. 문의

본 개인정보 처리방침과 관련하여 질문이 있는 경우, 문의 페이지에 제공된 지원 채널을 통해 개발자에게 연락해 주시기 바랍니다.
