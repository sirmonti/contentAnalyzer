Content Analyzer Erweiterung

Holen Sie sich einen kostenlosen API-Schlüssel

Um den Content Analyzer effektiv zu nutzen, müssen Sie einen KI-Anbieter konfigurieren. Während einige Anbieter für die Nutzung Gebühren erheben, gibt es hervorragende kostenlose Optionen.

Unten finden Sie Anleitungen dazu, wie Sie kostenlose API-Schlüssel erhalten oder Dienste auf beliebten Plattformen einrichten können: Google Gemini, OpenRouter, Groq, Mistral AI und Ollama.

1

Google Gemini

Google bietet Zugang zu seinen fortschrittlichen Gemini-Modellen über Google AI Studio. Sie bieten eine großzügige kostenlose Stufe für Entwickler. Beachten Sie, dass die Modelle, die kostenlos verwendet werden können, diejenigen sind, die das Wort „lite“ im Namen enthalten, wie zum Beispiel gemini-3.1-flash-lite oder gem1-flash-lite-latest.

  • Besuchen Sie die Google AI Studio-Website.
  • Melden Sie sich mit Ihrem Google-Konto an.
  • Klicken Sie im Navigationsmenü auf der linken Seite auf „Get API key“.
  • Klicken Sie auf die Schaltfläche „Create API key“. Sie können wählen, ob Sie den Schlüssel in einem bestehenden Google Cloud-Projekt erstellen oder AI Studio anweisen möchten, ein neues für Sie zu erstellen.
  • Kopieren Sie den generierten Schlüssel und fügen Sie ihn auf der Options-Seite des Content Analyzers unter den Gemini-Anbietereinstellungen ein.
2

OpenRouter.ai

OpenRouter ist eine einheitliche Schnittstelle für mehrere KI-Modelle. Es bündelt Modelle verschiedener Anbieter, und mehrere hochwertige Modelle sind völlig kostenlos verfügbar.

  • Besuchen Sie die OpenRouter.ai-Homepage.
  • Melden Sie sich an oder registrieren Sie sich mit einem bestehenden Konto (Google, GitHub usw.).
  • Navigieren Sie nach dem Einloggen zum Bereich „Keys“ im Hauptmenü oder in Ihren Kontoeinstellungen.
  • Klicken Sie auf „Create Key“. Geben Sie ihm einen Namen wie „Content Analyzer“.
  • Kopieren Sie Ihren neuen API-Schlüssel. Wählen Sie im Content Analyzer die Option OpenRouter als Anbieter aus, fügen Sie Ihren API-Schlüssel ein und wählen Sie die ID Ihres gewünschten Modells aus oder geben Sie diese ein (z. B. google/gemini-2.5-flash:free).
3

Groq

Groq bietet eine extrem schnelle Inferenz für Open-Source-KI-Modelle. Derzeit bieten sie eine kostenlose Stufe mit hoher Leistung für Entwickler an.

  • Besuchen Sie die Groq Console.
  • Melden Sie sich an oder registrieren Sie sich mit einem bestehenden Konto.
  • Navigieren Sie zur Sektion „API Keys“ in der Seitenleiste.
  • Klicken Sie auf „Create API Key“ und geben Sie ihm einen beschreibenden Namen.
  • Kopieren Sie den generierten API-Schlüssel. Wählen Sie im Content Analyzer die Option Groq als Anbieter aus, fügen Sie Ihren API-Schlüssel ein und wählen Sie Ihr gewünschtes Modell aus der Liste aus (z. B. llama-3.3-70b-versatile).
4

Mistral AI

Mistral AI bietet über La Plateforme Zugang zu hochmodernen Open-Source- und kommerziellen Modellen und bietet Entwicklern kostenlose Stufen zum Experimentieren an.

  • Besuchen Sie die Mistral AI Console.
  • Melden Sie sich an oder registrieren Sie sich in Ihrem Konto.
  • Navigieren Sie über die Workspace-Navigation zum Bereich „API Keys“.
  • Klicken Sie auf „Create new key“ und kopieren Sie Ihren generierten API-Schlüssel.
  • Wählen Sie im Content Analyzer die Option Mistral AI als Anbieter aus, fügen Sie Ihren API-Schlüssel ein und wählen Sie Ihr gewünschtes Modell aus der Liste aus (z. B. mistral-small-latest, mistral-large-latest oder codestral-latest).
5

Ollama (ollama.com)

Ollama bietet einen Online-API-Service, der es Ihnen ermöglicht, sich über deren Web-Plattform direkt mit gehosteten Modellen zu verbinden.

  • Besuchen Sie die Website Ollama.com.
  • Melden Sie sich in Ihrem Konto an oder registrieren Sie sich, falls Sie noch keines haben.
  • Klicken Sie auf Ihr Benutzermenü in der oberen rechten Ecke der Seite.
  • Wählen Sie die Option „Settings“.
  • Wählen Sie den Bereich „Keys“.
  • Klicken Sie auf „Add API key“ und generieren Sie Ihren API-Schlüssel.
  • Wählen Sie im Content Analyzer den Ollama-API-Typ aus, legen Sie die Basis-URL auf https://ollama.com/ fest und geben Sie die ID Ihres gewünschten Modells ein (z. B. gemma4:31b).
