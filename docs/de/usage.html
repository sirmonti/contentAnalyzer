Content Analyzer Erweiterung

Anleitung zur Verwendung und Konfiguration

Der Content Analyzer ist eine Browsererweiterung, die für die automatisierte Extraktion und Auswertung von semantischen Metadaten in komplexen Webumgebungen entwickelt wurde. Diese Erweiterung funktioniert in Firefox, Chrome und Chromium-basierten Browsern. Ihr Hauptzweck ist die Verarbeitung von Webinhalten durch die Weiterleitung an verschiedene Dienste der künstlichen Intelligenz (KI).

Im Gegensatz zu typischen Webseiten-Zusammenfassungsdiensten ermöglicht diese Erweiterung die Erstellung mehrerer benutzerdefinierter KI-Dienste, von denen jeder eine hochspezifische Eingabeaufforderung (Prompt) enthält, die genau festlegt, was die KI mit den gesammelten Informationen tun soll. Sie können es verwenden, um Code zu extrahieren, bestimmte Begriffe zu übersetzen, die Stimmung zu analysieren, gezielte Berichte zu erstellen und vieles mehr.

Hauptfunktionen

  • Benutzerdefinierte Inhaltsaufnahme: Sie können mithilfe eines interaktiven "Hover-Tools" einen bestimmten Teil einer Webseite auswählen oder die gesamte Seiteninhalte erfassen.
  • Mehrere benutzerdefinierte KI-Prompts und System-Prompts: Erstellen Sie verschiedene Dienste, die auf Ihre genauen Bedürfnisse zugeschnitten sind, mit benutzerdefinierten Eingabeaufforderungen und optionalen System-Prompts (z. B. "Artikel zusammenfassen", "JSON-Daten extrahieren", "ins Spanische übersetzen", benutzerdefinierte Assistenten-Personas usw.).
  • Domänenspezifische Dienste: Sie können Ihre benutzerdefinierten Dienste mit bestimmten Webdomänen verknüpfen. Dies trägt dazu bei, Ihre Erweiterung übersichtlich zu halten, indem nur relevante KI-Tools angezeigt werden.
  • Breite LLM-Kompatibilität: Unterstützt vollständig Verbindungen (einschließlich Text-Streaming) mit lokalen Servern über Ollama sowie Cloud-API-Anbieter wie OpenAI, Anthropic und Google Gemini.
2

Unterstützte KI-Anbieter

Diese Erweiterung ist so konzipiert, dass sie hochgradig flexibel ist und die Verbindung zu einer Vielzahl von branchenführenden KI-Modellen und lokalen Diensten ermöglicht. Derzeit werden folgende Anbieter unterstützt:

  • Claude (Anthropic): Zugriff auf die leistungsstarke Claude-Familie von Modellen über deren offizielle API.
  • Gemini (Google): Direkte Verbindung zu Googles fortschrittlichen Gemini-Modellen.
  • ChatGPT (OpenAI & Kompatibel): Vollständig kompatibel mit der OpenAI-API sowie jedem anderen Drittanbieterdienst, der ein OpenAI-kompatibles Endgerät anbietet.
  • Ollama: Führen Sie Modelle lokal und privat auf Ihrem eigenen Computer aus, ohne Daten in die Cloud zu senden.
3

Dynamische Tags für Prompts

Um Ihre KI-Prompts kontextbezogener und leistungsfähiger zu gestalten, können Sie die folgenden dynamischen Tags sowohl in Benutzer-Prompts als auch in System-Prompts verwenden. Die Erweiterung wird diese automatisch ersetzen, bevor der Prompt an das KI-Modell gesendet wird:

Tag Beschreibung
{DATE} Wird durch das aktuelle Datum in Ihrem lokalen Format ersetzt.
{HOUR} Wird durch die aktuelle Uhrzeit in Ihrem lokalen Format ersetzt.
{URL} Die vollständige URL der Webseite, die gerade verarbeitet wird.
{DOMAIN} Die Stammdomäne der Webseite, die verarbeitet wird.
{LANG} Die Sprache der Webseite.
{SYSLANG} Die aktuelle System-/Browsersprachenkonfiguration.
{TITLE} Der HTML-Titel der Webseite, die gerade verarbeitet wird.
4

Beispielkonfigurationen

Im Folgenden finden Sie einige Beispiele, wie Sie Ihre Dienste strukturieren können:

Beispiel 1: Mehrsprachiger Übersetzungsassistent

Dienstname: In lokale Sprache übersetzen
Verknüpfte Domänen: (Leer - Überall verfügbar)

Ich bin ein professioneller Übersetzer. Ich durchsufe eine Seite in der Sprache {LANG} unter {URL}, aber mein Browser ist auf {SYSLANG} eingestellt. Bitte übersetzen Sie den folgenden Inhalt genau in {SYSLANG} und behalten Sie dabei das ursprüngliche Markdown und die Textformatierung bei.

Beispiel 2: Code-Prüfer (domänenspezifisch)

Dienstname: Python-Code-Prüfung
Verknüpfte Domänen: github.com, gitlab.com, stackoverflow.com

Sie sind ein erfahrener Entwickler. Die unten angegebenen Code-Snippets wurden auf {DOMAIN} gefunden. Analysieren Sie den Code streng auf potenzielle Fehler, Sicherheitslücken und Code-Probleme. Erklären Sie nicht, was der Code tut, sondern listen Sie nur die Probleme auf und stellen Sie eine korrigierte Version bereit.

Beispiel 3: Extrahierer für tägliche Zusammenfassungen

Dienstname: Wichtige Entitäten extrahieren
Verknüpfte Domänen: news.ycombinator.com, techcrunch.com, bbc.com

Heute ist {DATE} um {HOUR}. Scannen Sie den folgenden Nachrichtenartikel und extrahieren Sie eine übersichtliche JSON-Liste, die die wichtigsten "Personen", "Organisationen" und "Standorte" enthält, die im Text erwähnt werden.

Beispiel 4: Benutzerdefinierte Assistenten-Persona (System-Prompt)

Dienstname: Mario-Assistent
System-Prompt:

Du bist Mario, ein kluger und scharfsinniger Assistent. Deine Aufgabe ist es, die dir zugewiesenen Aufgaben so effizient wie möglich zu erledigen. Bei Aufgaben, die zeitliche Bezüge haben, musst du beachten, dass heute {DATE} ist.

Benutzer-Prompt:

Analysiere den folgenden Text, der von {URL} abgerufen wurde, und erstelle eine Zusammenfassung der wichtigsten Punkte.
5

Browser-Installation

Die Installation erfolgt über das offizielle Repository oder durch Laden des entpackten Pakets im Entwicklermodus.

  • Google Chrome: Herunterladen aus dem Chrome Web Store.
  • Mozilla Firefox: Herunterladen von Firefox Add-ons.
  • Alternativ können Sie die entpackte Erweiterung im Entwicklermodus über chrome://extensions/ oder about:debugging laden.
info
Hinweis: Stellen Sie sicher, dass Sie die globalen Einstellungen (API-Schlüssel oder lokale Ollama-Instanzen) in der Einstellungsseite der Erweiterung richtig konfigurieren, bevor Sie Erfassungen durchführen.
