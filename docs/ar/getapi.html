احصل على مفتاح API مجاني

لاستخدام Content Analyzer بشكل فعال، ستحتاج إلى تكوين مزود للذكاء الاصطناعي. في حين أن بعض المزودين يفرضون رسومًا مقابل استخدامهم، إلا أن هناك خيارات مجانية ممتازة متاحة.

فيما يلي ستجد تعليمات حول كيفية الحصول على مفاتيح API مجانية أو إعداد الخدمات عبر المنصات الشائعة: Google Gemini و OpenRouter و Groq و Mistral AI و Ollama.

1

Google Gemini

تقدم Google الوصول إلى نماذج Gemini المتقدمة من خلال Google AI Studio. إنهم يقدمون طبقة مجانية سخية للمطورين. لاحظ أن النماذج التي يمكن استخدامها مجانًا هي تلك التي تحتوي على كلمة "lite" في اسمها، مثل gemini-3.1-flash-lite أو gemini-flash-lite-latest.

  • قم بزيارة موقع Google AI Studio.
  • سجّل الدخول باستخدام حساب Google الخاص بك.
  • في قائمة التنقل الموجودة على الجانب الأيسر، انقر فوق "Get API key.
  • انقر فوق الزر "Create API key. يمكنك اختيار إنشائه في مشروع Google Cloud موجود أو السماح لـ AI Studio بإنشاء مشروع جديد لك.
  • انسخ المفتاح الذي تم إنشاؤه والصقه في صفحة خيارات Content Analyzer ضمن إعدادات مزود Gemini.
2

OpenRouter.ai

OpenRouter هي واجهة موحدة للعديد من نماذج الذكاء الاصطناعي. إنه يجمع النماذج من مختلف المزودين، ويتوفر العديد من النماذج عالية الجودة مجانًا.

  • اذهب إلى الصفحة الرئيسية لـ OpenRouter.ai.
  • سجّل أو سجّل الدخول باستخدام حساب موجود (Google أو GitHub وما إلى ذلك).
  • بعد تسجيل الدخول، انتقل إلى قسم "Keys" من القائمة الرئيسية أو إعدادات حسابك.
  • انقر فوق "Create Key. أعطه اسمًا مثل "Content Analyzer".
  • انسخ مفتاح API الجديد الخاص بك. في Content Analyzer، يمكنك استخدام هذا المفتاح عن طريق تحديد خيار توافق OpenAI، وتعيين عنوان URL الأساسي على https://openrouter.ai/api/v1, وإدخال معرف النموذج الذي اخترته (على سبيل المثال، google/gemini-2.5-flash:free).
3

Groq

يوفر Groq استدلالًا سريعًا للغاية لنماذج الذكاء الاصطناعي مفتوحة المصدر. يقدمون حاليًا طبقة مجانية بأداء عالٍ للمطورين.

  • قم بزيارة Groq Console.
  • سجّل أو سجّل الدخول باستخدام حساب موجود.
  • انتقل إلى قسم "API Keys" في الشريط الجانبي.
  • انقر فوق "Create API Key وأعطه اسمًا وصفيًا.
  • انسخ مفتاح API الذي تم إنشاؤه. في Content Analyzer، استخدم خيار توافق OpenAI، وقم بتعيين عنوان URL الأساسي على https://api.groq.com/openai/v1, وأدخل معرف النموذج الذي اخترته (على سبيل المثال، llama3-8b-8192).
4

Mistral AI

توفر Mistral AI الوصول إلى النماذج التجارية والمفتوحة المتطورة من خلال La Plateforme، وتقدم طبقات مجانية للمطورين للتجربة.

  • قم بزيارة Mistral AI Console.
  • سجّل أو سجّل الدخول إلى حسابك.
  • انتقل إلى قسم "API Keys" من قائمة التنقل في مساحة العمل.
  • انقر فوق "Create new key وانسخ مفتاح API الذي تم إنشاؤه.
  • في Content Analyzer، حدد خيار توافق OpenAI، وقم بتعيين عنوان URL الأساسي على https://api.mistral.ai/v1, وأدخل معرف النموذج الذي اخترته (على سبيل المثال، mistral-small-latest).
5

Ollama (ollama.com)

يوفر Ollama خدمة API عبر الإنترنت تسمح لك بالاتصال مباشرةً بالنماذج المستضافة من خلال نظامها الأساسي على الويب.

  • قم بزيارة موقع Ollama.com.
  • سجّل الدخول إلى حسابك أو سجّل إذا لم يكن لديك واحد بعد.
  • انقر فوق قائمة المستخدم الموجودة في الزاوية اليمنى العليا من الصفحة.
  • حدد خيار "Settings.
  • حدد قسم "Keys.
  • انقر فوق "Add API key وقم بإنشاء مفتاح API الخاص بك.
  • في Content Analyzer، اختر نوع واجهة برمجة التطبيقات Ollama وقم بتعيين عنوان URL الأساسي على https://ollama.com/, وأدخل معرف النموذج الذي اخترته (على سبيل المثال، gemma4:31b).
