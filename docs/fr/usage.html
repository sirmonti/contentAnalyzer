Extension Content Analyzer

Guide d'utilisation et de configuration

Le Content Analyzer est une extension de navigateur conçue pour l'extraction automatique et l'évaluation de métadonnées sémantiques dans des environnements web complexes. Cette extension fonctionne sur Firefox, Chrome et les navigateurs basés sur Chromium ; son objectif principal est de traiter le contenu web en le faisant passer par divers services d'intelligence artificielle (IA).

Contrairement aux résumeurs de pages web classiques, cette extension vous permet de créer plusieurs services IA personnalisés, chacun avec un prompt très spécifique qui dicte exactement ce que l'IA doit faire avec les informations collectées. Vous pouvez l'utiliser pour extraire du code, traduire des termes spécifiques, analyser le sentiment, générer des rapports ciblés, et bien plus encore.

Fonctionnalités clés

  • Capture de contenu personnalisé : Vous pouvez facilement sélectionner une partie spécifique d'une page web à l'aide d'un « outil de survol » interactif, ou choisir de capturer l'intégralité du contenu de la page.
  • Multiples prompts IA et prompts système personnalisés : Créez différents services adaptés à vos besoins précis avec des prompts utilisateur personnalisés et des prompts système optionnels (par ex. : « Résumer l'article », « Extraire les données JSON », « Traduire en espagnol », personnages d'assistants personnalisés, etc.).
  • Services spécifiques au domaine : Vous pouvez lier vos services personnalisés à des domaines web spécifiques. Cela permet de garder votre extension épurée en n'affichant que les outils d'IA pertinents.
  • Large compatibilité avec les LLM : Prend en charge pleinement les connexes (y compris le flux de texte) avec des serveurs locaux via Ollama, ainsi que des fournisseurs d'API cloud tels qu'Anthropic (Claude), Google Gemini, Groq, OpenRouter, Mistral AI et OpenAI.
2

Fournisseurs d'IA pris en charge

Cette extension est conçue pour être très flexible, vous permettant de vous connecter à une variété de modèles d'intelligence artificielle de pointe et à des services locaux. Actuellement, elle prend en charge :

  • Claude (Anthropic) : Accédez à la puissante famille de modèles Claude via leur API officielle.
  • Gemini (Google) : Connectez-vous directement aux modèles Gemini avancés de Google.
  • Groq : Inférence ultra-rapide avec les modèles dédiés Llama, Mixtral et Gemma.
  • OpenRouter : Accès unifié à un vaste catalogue de modèles d'IA provenant de multiples fournisseurs.
  • Mistral AI : Connectez-vous aux modèles Mistral ouverts et commerciaux de pointe via leur API officielle.
  • ChatGPT (OpenAI & compatibles) : Entièrement compatible avec l'API d'OpenAI, ainsi qu'avec tout autre service tiers proposant un point de terminaison compatible avec OpenAI.
  • Ollama (ou compatibles) : Exécutez des modèles localement et en toute confidentialité sur votre propre machine sans envoyer de données vers le cloud.
3

Tags dynamiques du prompt

Pour rendre vos prompts IA plus contextuels et puissants, vous pouvez utiliser les tags dynamiques suivants dans les prompts utilisateur et les prompts système. L'extension les remplacera automatiquement avant d'envoyer le prompt au modèle d'IA :

Tag Description
{DATE} Remplacé par la date actuelle selon votre format local.
{HOUR} Remplacé par l'heure actuelle selon votre format local.
{URL} L'URL complète de la page web actuellement en cours de traitement.
{DOMAIN} Le domaine racine de la page web en cours de traitement.
{LANG} La langue de la page web.
{SYSLANG} La configuration actuelle de la langue du système/navigateur.
{TITLE} Le titre HTML de la page web actuellement en cours de traitement.
4

Exemples de configuration

Voici quelques exemples montrant comment vous pouvez structurer vos services :

Exemple 1 : Assistant de traduction multilingue

Nom du service : Traduire vers la langue locale
Domaines liés : (Vide - Disponible partout)

Agissez en tant que traducteur professionnel. Je consulte un site en langue {LANG} à l'adresse {URL}, mais mon navigateur est configuré en {SYSLANG}. Veuillez traduire fidèlement le contenu suivant en {SYSLANG}, en conservant le formatage markdown et textuel original.

Exemple 2 : Correcteur de code (Spécifique au domaine)

Nom du service : Revue de code Python
Domaines liés : github.com, gitlab.com, stackoverflow.com

Vous êtes un développeur expert. Les extraits de code ci-dessous ont été trouvés sur {DOMAIN}. Analysez le code strictement pour identifier d'éventuels bugs, des failles de sécurité et des problèmes de structure (code smells). Ne décrivez pas ce que fait le code, listez simplement les problèmes et fournissez une version corrigée.

Exemple 3 : Extracteur de briefing quotidien

Nom du service : Extraire les entités clés
Domaines liés : news.ycombinator.com, techcrunch.com, bbc.com

Nous sommes le {DATE} à {HOUR}. Parcourez l'article de presse suivant et extrayez une liste JSON propre contenant les principaux « Personnes », « Organismes » et « Lieux » mentionnés dans le texte.

Exemple 4 : Personnalité d'assistant personnalisé (Prompt système)

Nom du service : Assistant Mario
Prompt système :

Vous êtes Mario, un assistant ingénieux et vif. Votre rôle est d'accomplir les tâches qui vous sont confiées le plus efficacement possible. Pour les tâches contenant des références temporelles, n'oubliez pas que nous sommes aujourd'hui le {DATE}

Prompt utilisateur :

Analysez le texte suivant capturé depuis {URL} et fournissez un résumé des points principaux.
5

Installation du navigateur

Le processus d'installation s'effectue via le dépôt officiel ou en chargeant le paquet non compressé en mode développeur.

  • Google Chrome : Télécharger depuis le Chrome Web Store.
  • Mozilla Firefox : Télécharger depuis les modules complémentaires Firefox.
  • Alternativement, vous pouvez charger l'extension non compressée en mode développeur via chrome://extensions/ ou about:debugging.
info
Note : Assurez-vous d'avoir configuré correctement les paramètres globaux (clés API ou instances Ollama locales) dans la page Options de l'extension avant d'effectuer toute capture.
