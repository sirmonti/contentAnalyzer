Obtenir une clé API gratuite

Pour utiliser efficacement le Content Analyzer, vous devrez configurer un fournisseur d'IA. Bien que certains fournisseurs facturent leur utilisation, il existe d'excellentes options gratuites.

Vous trouverez ci-dessous des instructions sur la manière d'obtenir des clés API gratuites ou de configurer des services sur des plateformes populaires : Google Gemini, OpenRouter, Groq, Mistral AI et Ollama.

1

Google Gemini

Google offre un accès à ses modèles Gemini avancés via Google AI Studio. Ils proposent un niveau gratuit généreux pour les développeurs. Notez que les modèles pouvant être utilisés gratuitement sont ceux contenant le mot "lite" dans leur nom, tels que gemini-3.1-flash-lite ou gemini-flash-lite-latest.

  • Visitez le site Google AI Studio.
  • Connectez-vous avec votre compte Google.
  • Dans le menu de navigation de gauche, cliquez sur "Obtenir une clé API".
  • Cliquez sur le bouton "Créer une clé API". Vous pouvez choisir de la créer dans un projet Google Cloud existant ou laisser AI Studio en créer un nouveau pour vous.
  • Copiez la clé générée et collez-la dans la page Options du Content Analyzer sous les paramètres du fournisseur Gemini.
2

OpenRouter.ai

OpenRouter est une interface unifiée pour plusieurs modèles d'IA. Il regroupe des modèles provenant de divers fournisseurs, et plusieurs modèles de haute qualité sont disponibles entièrement gratuitement.

  • Rendez-vous sur la page d'accueil d' OpenRouter.ai.
  • Inscrivez-vous ou connectez-vous à l'aide d'un compte existant (Google, GitHub, etc.).
  • Une fois connecté, accédez à la section "Clés" depuis le menu principal ou les paramètres de votre compte.
  • Cliquez sur "Créer une clé". Donnez-lui un nom comme "Content Analyzer".
  • Copiez votre nouvelle clé API. Dans Content Analyzer, sélectionnez l'option de fournisseur OpenRouter, collez votre clé API, et sélectionnez ou saisissez l'ID du modèle choisi (par exemple, google/gemini-2.5-flash:free).
3

Groq

Groq propose une inférence extrêmement rapide pour les modèles d'IA en open-source. Ils offrent actuellement un niveau gratuit à haute performance pour les développeurs.

  • Visitez la console Groq.
  • Inscrivez-vous ou connectez-vous à l'aide d'un compte existant.
  • Accédez à la section "Clés API" dans la barre latérale.
  • Cliquez sur "Créer une clé API" et donnez-lui un nom descriptif.
  • Copiez la clé API générée. Dans Content Analyzer, sélectionnez l'option de fournisseur Groq, collez votre clé API, et sélectionnez votre modèle choisi dans la liste (par exemple, llama-3.3-70b-versatile).
4

Mistral AI

Mistral AI offre un accès à des modèles ouverts et commerciaux de pointe via La Plateforme, offrant des niveaux gratuits pour permettre aux développeurs d'expérimenter.

  • Visitez la console Mistral AI.
  • Inscrivez-vous ou connectez-vous à votre compte.
  • Accédez à la section "Clés API" depuis la navigation de l'espace de travail.
  • Cliquez sur "Créer une nouvelle clé" et copiez votre clé API générée.
  • Dans Content Analyzer, sélectionnez l'option de fournisseur Mistral AI, collez votre clé API, et sélectionnez votre modèle choisi dans la liste (par exemple, mistral-small-latest, mistral-large-latest, ou codestral-latest).
5

Ollama (ollama.com)

Ollama propose un service d'API en ligne vous permettant de vous connecter directement à des modèles hébergés via leur plateforme web.

  • Visitez le site Ollama.com.
  • Connectez-vous à votre compte ou inscrivez-vous si vous n'en avez pas encore.
  • Cliquez sur votre menu utilisateur situé dans le coin supérieur droit de la page.
  • Sélectionnez l'option "Paramètres".
  • Sélectionnez la section "Clés".
  • Cliquez sur "Ajouter une clé API" et générez votre clé API.
  • Dans Content Analyzer, choisissez le type d'API Ollama et définissez la Base URL sur https://ollama.com/, puis saisissez l'ID du modèle choisi (par exemple, gemma4:31b).
