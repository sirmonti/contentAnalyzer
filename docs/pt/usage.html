Extensão Analisador de Conteúdo

Guia de Uso e Configuração

O Analisador de Conteúdo é uma extensão de navegador projetada para a extração e avaliação automatizada de metadados semânticos em ambientes web complexos. Esta extensão funciona no Firefox, Chrome e navegadores derivados do Chromium; seu objetivo principal é processar o conteúdo da web, passando-o por vários serviços de Inteligência Artificial (IA).

Ao contrário dos resumos típicos de páginas da web, esta extensão permite criar vários serviços de IA personalizados, cada um com um prompt altamente específico que define exatamente o que a IA deve fazer com as informações coletadas. Você pode usá-la para extrair código, traduzir termos específicos, analisar sentimentos, gerar relatórios direcionados e muito mais.

Principais Recursos

  • Captura de Conteúdo Personalizada: Você pode selecionar facilmente uma parte específica de uma página da web usando uma "ferramenta interativa" ou optar por capturar todo o conteúdo da página.
  • Múltiplos Prompts e Prompts de Sistema Personalizados: Crie diferentes serviços personalizados para suas necessidades exatas, com prompts de usuário personalizados e prompts de sistema opcionais (por exemplo, "Resumir artigo", "Extrair dados JSON", "Traduzir para espanhol", personalidades de assistente personalizadas, etc.).
  • Serviços Específicos de Domínio: Você pode vincular seus serviços personalizados a domínios da web específicos. Isso ajuda a manter sua extensão organizada, mostrando apenas as ferramentas de IA relevantes.
  • Ampla Compatibilidade com LLMs: Suporta totalmente conexões (incluindo streaming de texto) com servidores locais via Ollama, bem como provedores de API em nuvem, como OpenAI, Anthropic e Google Gemini.
2

Provedores de IA Suportados

Esta extensão foi projetada para ser altamente flexível, permitindo que você se conecte a uma variedade de modelos de Inteligência Artificial líderes do setor e serviços locais. Atualmente, ela suporta:

  • Claude (Anthropic): Acesse a poderosa família de modelos Claude por meio de sua API oficial.
  • Gemini (Google): Conecte-se diretamente aos avançados modelos Gemini do Google.
  • ChatGPT (OpenAI e Compatíveis): Totalmente compatível com a API da OpenAI, bem como qualquer outro serviço de terceiros que ofereça um endpoint compatível com a OpenAI.
  • Ollama: Execute modelos localmente e com privacidade em sua própria máquina, sem enviar dados para a nuvem.
3

Tags Dinâmicas para Prompts

Para tornar seus prompts de IA mais contextuais e poderosos, você pode usar as seguintes tags dinâmicas em prompts de usuário e prompts de sistema. A extensão substituirá automaticamente essas tags antes de enviar o prompt para o modelo de IA:

Tag Descrição
{DATE} Substituído pela data atual em seu formato local.
{HOUR} Substituído pela hora atual em seu formato local.
{URL} A URL completa da página da web que está sendo processada.
{DOMAIN} O domínio raiz da página da web que está sendo processada.
{LANG} O idioma da página da web.
{SYSLANG} A configuração atual de idioma do sistema/navegador.

Exemplos de Configurações

Abaixo estão alguns exemplos que mostram como você pode estruturar seus serviços:

Exemplo 1: Assistente de Tradução Multilíngue

Nome do Serviço: Traduzir para o idioma local
Domínios vinculados: (Vazio - Disponível em todos os lugares)

Atue como um tradutor profissional. Estou navegando em um site no idioma {LANG} em {URL}, mas meu navegador está configurado para {SYSLANG}. Traduza com precisão o seguinte conteúdo para {SYSLANG}, mantendo a formatação original de markdown e texto.

Exemplo 2: Avaliador de Código (Específico do Domínio)

Nome do Serviço: Análise de código Python
Domínios vinculados: github.com, gitlab.com, stackoverflow.com

Você é um desenvolvedor experiente. Os trechos de código fornecidos abaixo foram encontrados em {DOMAIN}. Analise o código estritamente para identificar possíveis bugs, vulnerabilidades de segurança e problemas de codificação. Não explique o que o código faz; apenas liste os problemas e forneça uma versão corrigida.

Exemplo 3: Extrator de Informações Diárias

Nome do Serviço: Extrair Entidades Chave
Domínios vinculados: news.ycombinator.com, techcrunch.com, bbc.com

Hoje é {DATE} às {HOUR}. Analise o seguinte artigo de notícias e extraia uma lista JSON organizada contendo os principais "Pessoas", "Organizações" e "Locais" mencionados no texto.

Exemplo 4: Personalidade de Assistente Personalizada (Prompt do Sistema)

Nome do Serviço: Assistente Mario
Prompt do Sistema:

Você é o Mario, um assistente inteligente e perspicaz. Sua tarefa é cumprir as tarefas atribuídas a você da forma mais eficiente possível. Nas tarefas que têm referências temporais, você deve ter em mente que hoje é {DATE}.

Prompt do Usuário:

Analise o seguinte texto capturado de {URL} e forneça um resumo dos pontos principais.
5

Instalação no Navegador

O processo de instalação é feito através do repositório oficial ou carregando o pacote descompactado em modo de desenvolvedor.

  • Google Chrome: Baixe na Chrome Web Store.
  • Mozilla Firefox: Baixe no Add-ons do Firefox.
  • Alternativamente, você pode carregar a extensão descompactada em modo de desenvolvedor via chrome://extensions/ ou about:debugging.
info
Observação: Certifique-se de ter configurado corretamente as configurações globais (chaves de API ou instâncias locais do Ollama) na página de Opções da extensão antes de executar qualquer captura.
