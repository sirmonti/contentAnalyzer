Estensione Analizzatore di Contenuti

Guida all'utilizzo e alla configurazione

L'Analizzatore di Contenuti è un'estensione per browser progettata per l'estrazione e la valutazione automatica di metadati semantici in ambienti web complessi. Questa estensione funziona su Firefox, Chrome e browser derivati da Chromium; il suo scopo principale è elaborare i contenuti web, passandoli attraverso vari servizi di Intelligenza Artificiale (IA).

A differenza dei tipici strumenti di riepilogo di pagine web, questa estensione consente di creare più servizi di IA personalizzati, ciascuno con un prompt altamente specifico che determina esattamente cosa l'IA deve fare con le informazioni raccolte. Puoi usarla per estrarre codice, tradurre termini specifici, analizzare il sentiment, generare report mirati e molto altro.

1

Funzionalità principali

  • Acquisizione di contenuti personalizzata: È possibile selezionare facilmente una parte specifica di una pagina web utilizzando uno strumento interattivo "a cursore", oppure scegliere di acquisire l'intero contenuto della pagina.
  • Prompt e prompt di sistema personalizzati multipli: Crea diversi servizi personalizzati in base alle tue esigenze specifiche, con prompt utente personalizzati e prompt di sistema opzionali (ad esempio, "Riassumi l'articolo", "Estrai i dati JSON", "Traduci in spagnolo", personalità di assistente personalizzate, ecc.).
  • Servizi specifici per dominio: Puoi collegare i tuoi servizi personalizzati a domini web specifici. Questo aiuta a mantenere l'estensione ordinata, mostrando solo gli strumenti di IA pertinenti.
  • Ampia compatibilità con gli LLM: Supporta completamente le connessioni (incluso lo streaming di testo) con server locali tramite Ollama, nonché provider di API cloud come OpenAI, Anthropic e Google Gemini.
2

Provider di IA supportati

Questa estensione è progettata per essere altamente flessibile, consentendo di connettersi a una varietà di modelli di Intelligenza Artificiale e servizi locali leader del settore. Attualmente, supporta:

  • Claude (Anthropic): Accedi alla potente famiglia di modelli Claude tramite la loro API ufficiale.
  • Gemini (Google): Connettiti direttamente agli avanzati modelli Gemini di Google.
  • ChatGPT (OpenAI e compatibili): Completamente compatibile con l'API di OpenAI, nonché con qualsiasi altro servizio di terze parti che offre un endpoint compatibile con OpenAI.
  • Ollama: Esegui modelli in locale e in modo privato sulla tua macchina, senza inviare dati al cloud.
3

Tag dinamici per i prompt

Per rendere i tuoi prompt di IA più contestuali e potenti, puoi utilizzare i seguenti tag dinamici sia nei prompt utente che nei prompt di sistema. L'estensione sostituirà automaticamente questi tag prima di inviare il prompt al modello di IA:

Tag Descrizione
{DATE} Sostituito dalla data corrente nel formato locale.
{HOUR} Sostituito dall'ora corrente nel formato locale.
{URL} L'URL completo della pagina web attualmente in elaborazione.
{DOMAIN} Il dominio principale della pagina web in elaborazione.
{LANG} La lingua della pagina web.
{SYSLANG} La configurazione corrente della lingua del sistema/browser.
{TITLE} Il titolo HTML della pagina web attualmente in elaborazione.
4

Esempi di configurazione

Di seguito sono riportati alcuni esempi che mostrano come puoi strutturare i tuoi servizi:

Esempio 1: Assistente di traduzione multilingue

Nome del servizio: Traduci nella lingua locale
Domini collegati: (Vuoto - Disponibile ovunque)

Agisci come un traduttore professionista. Sto navigando in un sito nella lingua {LANG} all'indirizzo {URL}, ma il mio browser è impostato su {SYSLANG}. Per favore, traduci accuratamente il seguente contenuto in {SYSLANG}, mantenendo intatta la formattazione originale del markdown e del testo.

Esempio 2: Revisore di codice (specifico per dominio)

Nome del servizio: Revisione del codice Python
Domini collegati: github.com, gitlab.com, stackoverflow.com

Sei uno sviluppatore esperto. I frammenti di codice forniti di seguito sono stati trovati su {DOMAIN}. Analizza il codice per potenziali bug, vulnerabilità di sicurezza e problemi di stile del codice. Non spiegare cosa fa il codice, elenca solo i problemi e fornisci una versione corretta.

Esempio 3: Estrattore di informazioni per il briefing giornaliero

Nome del servizio: Estrai le entità chiave
Domini collegati: news.ycombinator.com, techcrunch.com, bbc.com

Oggi è {DATE} alle {HOUR}. Scansiona il seguente articolo di notizie ed estrai una lista JSON ordinata contenente i principali "Personaggi", "Organizzazioni" e "Luoghi" menzionati nel testo.

Esempio 4: Personalità di assistente personalizzata (prompt di sistema)

Nome del servizio: Assistente Mario
Prompt di sistema:

Sei Mario, un assistente intelligente e perspicace, il tuo compito è svolgere le attività assegnate nel modo più efficiente possibile. Nelle attività che hanno riferimenti temporali, devi tenere presente che oggi è {DATE}.

Prompt utente:

Analizza il seguente testo acquisito da {URL} e fornisce un riepilogo dei punti principali.
5

Installazione nel browser

L'installazione avviene tramite il repository ufficiale o caricando il pacchetto non compresso in modalità sviluppatore.

  • Google Chrome: Scarica dal Chrome Web Store.
  • Mozilla Firefox: Scarica dagli Add-on di Firefox.
  • In alternativa, puoi caricare l'estensione non compresso in modalità sviluppatore tramite chrome://extensions/ o about:debugging.
info
Nota: Assicurati di aver configurato correttamente le impostazioni globali (chiavi API o istanze Ollama locali) nella pagina delle opzioni dell'estensione prima di eseguire qualsiasi acquisizione.
