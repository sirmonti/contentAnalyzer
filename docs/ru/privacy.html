Политика конфиденциальности

Последнее обновление: апрель 2026 г.

1. Введение

Расширение для Chrome «contentAnalyzer» («Расширение») предназначено для обработки содержимого текущей веб-страницы с использованием сервисов искусственного интеллекта, настроенных пользователем. Настоящая Политика конфиденциальности разъясняет наши обязательства по защите вашей конфиденциальности и то, как обрабатываются данные.

2. Отсутствие сбора данных разработчиком

Мы превыше всего ценим вашу конфиденциальность. Разработчик данного Расширения не собирает, не хранит и не передает какие-либо ваши персональные данные, историю просмотров или обработанный контент на любой сервер под контролем разработчика.

Все настройки конфигурации (такие как API-ключи или пользовательские запросы) хранятся локально в памяти вашего браузера (например, chrome.storage.local) и никогда не доступны разработчику.

3. Передача данных сторонним сервисам

Для обеспечения своей основной функциональности Расширение передает содержимое веб-страницы, которую вы выбрали для анализа, стороннему поставщику услуг ИИ («Сервис ИИ»), который был настроен вами в параметрах.

3.1. Настраиваемые пользователем сервисы

Расширение взаимодействует только с конкретными конечными точками (endpoints) или API, предоставленными пользователем. Поскольку эти сервисы выбираются и настраиваются пользователем, разработчик «contentAnalyzer» не контролирует то, как сторонние сайты обрабатывают данные, отправленные им.

3.2. Политика конфиденциальности сторонних лиц

Разработчик не несет ответственности за методы обеспечения конфиденциальности, политику хранения данных или меры безопасности Сервисов ИИ, которые вы выбираете для использования. Перед использованием Расширения с конкретным сервисом мы настоятельно рекомендуем вам ознакомиться с Политикой конфиденциальности и Условиями обслуживания этого поставщика.

4. Разрешения

Для работы Расширения требуются следующие разрешения:

  • activeTab или <all_urls>: для чтения содержимого страницы, которую вы хотите проанализировать.
  • storage: для сохранения вашей конфигурации и настроек API локально.
  • разрешения хоста: Для отправки контента в API Сервиса ИИ, который вы указали.

5. Безопасность

Хотя Расширение облегчает передачу данных через стандартные веб-протоколы, безопасность данных после их выхода из вашего браузера полностью зависит от Сервиса ИИ, который вы настроили. Мы рекомендуем использовать сервисы, предоставляющие защищенные (HTTPS) конечные точки API.

6. Изменения в этой Политике

Разработчик оставляет за собой право обновлять данную Политику конфиденциальности в любое время. Любые изменения будут отражены в новой версии Расширения и обновлены на этой странице.

7. Контактная информация

Если у вас возникнут вопросы относительно этой Политики конфиденциальности, пожалуйста, свяжитесь с разработчиком через каналы поддержки, указанные на странице контактов.
