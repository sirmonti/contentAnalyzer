Расширение Content Analyzer

Получите бесплатный API-ключ

Для эффективного использования Content Analyzer вам потребуется настроить провайдера ИИ. Хотя некоторые провайдеры взимают плату за использование, доступны отличные бесплатные варианты.

Ниже вы найдете инструкции по получению бесплатных API-ключей или настройке сервисов на популярных платформах: Google Gemini, OpenRouter, Groq, Mistral AI и Ollama.

1

Google Gemini

Google предоставляет доступ к своим продвинутым моделям Gemini через Google AI Studio. Они предлагают щедрый бесплатный уровень для разработчиков. Обратите внимание, что для бесплатного использования доступны те модели, в названии которых содержится слово «lite», например, gemini-3.1-flash-lite или gemini-flash-lite-latest.

  • Посетите веб-сайт Google AI Studio.
  • Войдите в систему под своей учетной записью Google.
  • В левом навигационном меню нажмите на «Get API key».
  • Нажмите кнопку «Create API key». Вы можете создать ключ в существующем проекте Google Cloud или позволить AI Studio создать новый проект для вас.
  • Скопируйте сгенерированный ключ и вставьте его на странице настроек (Options) Content Analyzer в разделе настроек провайдера Gemini.
2

OpenRouter.ai

OpenRouter — это единый интерфейс для множества моделей ИИ. Он объединяет модели от различных провайдеров, при этом несколько высококачественных моделей доступны совершенно бесплатно.

  • Перейдите на главную страницу OpenRouter.ai.
  • Зарегистрируйтесь или войдите в систему, используя существующую учетную запись (Google, GitHub и т. д.).
  • После входа в систему перейдите к разделу «Keys» в главном меню или в настройках вашего аккаунта.
  • Нажмите «Create Key». Дайте ему название, например, «Content Analyzer».
  • Скопируйте свой новый API-ключ. В Content Analyzer выберите опцию провайдера OpenRouter, вставьте ваш API-ключ и выберите или введите ID выбранной вами модели (например, google/gemini-2.5-flash:free).
3

Groq

Groq обеспечивает чрезвычайно быстрый вывод (inference) для моделей ИИ с открытым исходным кодом. В настоящее время они предлагают бесплатный уровень с высокой производительностью для разработчиков.

  • Посетите Groq Console.
  • Зарегистрируйтесь или войдите в систему, используя существующую учетную запись.
  • Перейдите к разделу «API Keys» в боковой панели.
  • Нажмите «Create API Key» и дайте ему понятное название.
  • Скопируйте сгенерированный API-ключ. В Content Analyzer выберите опцию провайдера Groq, вставьте свой API-ключ и выберите нужную модель из списка (например, llama-3.3-70b-versatile).
4

Mistral AI

Mistral AI предоставляет доступ к передовым открытым и коммерческим моделям через La Plateforme, предлагая бесплатные уровни для экспериментов разработчиков.

  • Посетите Mistral AI Console.
  • Зарегистрируйтесь или войдите в свою учетную запись.
  • Перейдите к разделу «API Keys» в навигации рабочей области.
  • Нажмите «Create new key» и скопируйте ваш сгенерированный API-ключ.
  • В Content Analyzer выберите опцию провайдера Mistral AI, вставьте ваш API-ключ и выберите нужную модель из списка (например, mistral-small-latest, mistral-large-latest или codestral-latest).
5

Ollama (ollama.com)

Ollama предоставляет онлайн-сервис API, позволяющий напрямую подключаться к размещенным моделям через их веб-платформу.

  • Посетите сайт Ollama.com.
  • Войдите в свою учетную запись или зарегистрируйтесь, если у вас еще нет аккаунта.
  • Нажмите на меню пользователя в правом верхнем углу страницы.
  • Выберите опцию «Settings».
  • Выберите раздел «Keys».
  • Нажмите «Add API key» и создайте свой API-ключ.
  • В Content Analyzer выберите тип API Ollama, установите базовый URL (Base URL) на https://ollama.com/ и введите ID выбранной модели (например, gemma4:31b).
